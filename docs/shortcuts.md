# Горячие клавиши — начальный обязательный каталог

Это проектируемые назначения из спецификации, **не реализованные shortcuts**. Windows сейчас, Cmd-эквиваленты проверяются с Mac позже. Все назначения переназначаемы через settings; контекст и конфликты разрешаются в command registry. Полная сверка Office shortcuts и оставшиеся команды — открытая работа, этот начальный список не выдаётся за полный.

| Команда | Windows | macOS позже | Контекст |
|---|---|---|---|
| Жирный |Ctrl+B|Cmd+B|форматируемый текст|
| Курсив |Ctrl+I|Cmd+I|форматируемый текст|
| Подчёркивание |Ctrl+U|Cmd+U|форматируемый текст|
| Сохранить |Ctrl+S|Cmd+S|локальный документ; облачный уже autosave|
| Палитра команд |Ctrl+K|Cmd+K|app|
| AI-панель |Ctrl+J|Cmd+J|AI enabled, document context|
| Правка ячейки |F2|F2|Sheets|
| Показ с начала |F5|F5|Slides|
| Показ с текущего |Shift+F5|Shift+F5|Slides|

Критерии: доступ с клавиатуры/Narrator, справка команды показывает actual remapping, CJK IME shortcuts не перехватываются во время композиции; изменения доступны через ops и безопасный MCP settings contract. Исходные команды в docs/MCP.md не содержат готовой схемы remapping — mcp-gaps.md.
