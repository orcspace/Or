# TrineDocs 0.0.1

Первый стабильный выпуск TrineDocs — офисный пакет для Windows (Документы, Таблицы, Презентации), работающий с форматами Office.

## Главное

- **AI-чат в боковой панели.** Ассистент работает через ваш собственный Claude Code или Codex CLI: используется ваш вход и подписка, TrineDocs ключей не хранит. Ассистент видит открытые документы через встроенный MCP-сервер. Каждая его правка показывается чёрным AI-курсором со следом, а во вкладке «Изменения» её можно принять или откатить.
- **Таблицы и вёрстка DOCX как в Word.** Применяются поля ячеек (`tblCellMar`), интервалы из стиля таблицы, минимальная высота строк, реальные метрики шрифтов, интервал «точно» и «минимум», а также перенос с висячими пробелами. Документы больше не становятся длиннее, чем в Word.
- Табличные документы: объединённые ячейки, выравнивание по вертикали, таблицы без границ, видимый курсор в ячейке.
- Документы по умолчанию сохраняются в форматах Office (`.docx`, `.xlsx`, `.pptx`). Формат можно выбрать в «Сохранить как», PDF тоже доступен.
- Кнопка «Удалить пустую страницу».
- Картинки поверх ячеек в Таблицах, редактирование таблиц на слайдах, полный набор MCP-инструментов.

## Установка

Запустите `TrineDocs-Setup.exe`. Приложение ставится для текущего пользователя в `%LOCALAPPDATA%\Programs\TrineDocs`, права администратора не нужны. Для тихой установки используйте `TrineDocs-Setup.exe /S`.

Установщик не подписан цифровой подписью, поэтому Windows SmartScreen может показать предупреждение.

## Для AI-чата

Установите [Claude Code](https://claude.com/claude-code) или Codex CLI и выполните вход: «⋯ → Войти» в панели чата или в терминале.
