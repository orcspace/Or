# Sheets: паритет и проверка реализации

Дата: 2026-10-13. Это матрица фактической реализации, а не заявление о полном паритете с Excel.
Источники проверены в браузере: [каталог функций Microsoft](https://support.microsoft.com/en-us/excel/excel-functions-alphabetical), [ограничения Excel](https://support.microsoft.com/en-us/excel/excel-specifications-and-limits).
Excel имеет 1 048 576 строк и 16 384 столбца; адреса Sheets используют эти пределы. Вызов на диапазон ограничен 100 000 ячеек. Один пересчёт имеет безопасный предел 1 млн шагов/64 МБ materialized reference values; превышение возвращает #NUM!, поэтому полный Excel-паритет/100k тяжёлых формул не заявлен. Предел импорта — 64 МБ с проверкой ZIP, 1 млн непустых ячеек и 2 млн ячеек в прямоугольнике XLSX. Ограничения Sheets явно меньше полного Excel.

## Проверки

Код содержит более 150 числовых formula regression cases, отдельные проверки текста/логики/ошибок, Unicode, lazy branches, циклов, межлистовых ссылок/rename, stable IDs/structural shifts, CSV roundtrip и XLSX values/formulas/styles/charts roundtrip. Итог запуска следует брать из release-review; до фактического запуска тесты не считаются прошедшими. Корпус 50 XLSX, fuzz, Windows IME/DPI и сравнение с Microsoft Excel не проведены.


## Вторая волна ревью

Исправлены непрерывные диапазоны при удалении строк/столбцов (сокращение вместо ошибочного #REF! на частично удалённом диапазоне), names при rename/structural edit, вечный #REF! для удалённого листа, сдвиг selection/freeze/chart anchors и bounds метаданных. Нативные адреса должны быть каноническими; пересекающиеся merges отклоняются за O(n log n).

Preflight до calamine теперь ограничивает sharedStrings count/uniqueCount (защита reserve), индекс shared formula si (защита resize), глубину/DTD всех XML, expanded text/formula budget и implicit row counters. Разница систем 1900/1904 составляет 1462 дня; вместо неверного сдвига даты текущий импорт отклоняет 1904. Ошибка чтения формул больше не скрывается.

Добавлены регрессии для локального календаря, shrinking диапазонов, metadata overflow/transactionality, sheet deletion, lazy lookup fallback/wildcards/modes, expansion/overflow/nonfinite text, merge overlap, shared string/formula allocation bombs и time formats. Результат их выполнения фиксирует root в общем release-review. Это дополнение само по себе не означает зелёные tests или готовый релиз.
