S3-10 опирается на [W3C XML1.0 §2.2](https://www.w3.org/TR/xml/#charsets). Это проверка допустимых scalar, а не полный XML validator. UTF-16 и непрозрачные бинарные части не перекодируются. Существующая обработка soft/page breaks Docs остаётся отдельной.

Новая фича вне счёта: замечания инспектора хранят типизированные stable targets. Клик переводит к абзацу Docs (для картинки — к абзацу-якорю), существующей видимой ячейке Sheets или объекту Slides. До перехода проверяются версия, наличие объекта и скрытое состояние. Устаревшие/скрытые результаты остаются в отчёте с отключённым переходом. Навигация не создаёт undo; незавершённый ввод перед переключением фиксируется обычным путём ops. Переход к скрытому содержимому и автоисправления не заявлены.

Ограничения: семантическая валидация инструмента после flush может потребовать завершения ввода; полный Office parity, сложная вёрстка, OOXML round-trip и точность эвристик Slides не доказаны. Модельная замена через MCP требует собственных image bytes — read_content является представлением для чтения, не полным dump для replace_document_model.

Два независимых ревьюера прочитали итоговый root diff; блокеров по исходнику не осталось. Covered merge child отключён также на стороне инспектора; fixture проверки hidden-sheet errors вызывает set_cell с пересчётом. Эти уточнения новой навигации и старого теста не добавлены в квоту.
