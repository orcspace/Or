# Slides: минимализм и ревью (2026-10-13)

Область: `crates/trinedocs/src/slides/editor.rs`. Общую оболочку и цвета интегрирует root.

## Интерфейс

- Вместо четырёх вкладок с двухрядными группами — одна строка: «Новый слайд», «Вставка», «Объект», «Оформление», «Вид», «Показ».
- Вторичные команды открываются в настоящих меню. Сохранены создание/копирование/удаление слайдов, макеты, темы, 16:9/4:3; вставка текста, фигур, изображений, таблиц и диаграмм; выравнивание, слои и группы.
- Свойства и заметки закрыты по умолчанию и доступны в меню «Вид» и нижней строке. На широком окне миниатюры видны; их можно скрыть. На узком окне панели открываются отдельными окнами.
- Холст получает освобождённые ширину и высоту. Масштаб, сетка и привязка доступны в «Виде». «Вписать в окно» сбрасывает масштаб.
- Свойства первого выделенного объекта сохраняют формат текста, геометрию, цвета, данные таблиц/диаграмм и анимацию. Переходы, фон, раздел и скрытие слайда также сохранены.

## Исправления и проверка фокуса

- Два UI-теста действительно обнаружили дефект production layout: при viewport 1250×820 холст имел границы `[668.8, 845.0]–[761.2, 897.0]`. Клик был вне экрана; старые и новые границы совпадали. Причина не в раннем кадре шрифтов.
- Панели явно получают вертикальную раскладку вместо наследования горизонтальной раскладки родителя. Высота прокрутки команд ограничена; резерв для заметок выделяется только при их открытии.
- Canvas сохраняет focus lock стрелок. Перемещение/Delete требуют фокуса canvas; попадание курсора мыши на canvas само по себе не запускает команды.
- Команды объектов не выполняются при редактировании текста, открытом меню или окне «Текст объекта». Clipboard обрабатывается после полей заметок и текста. F5 и окна редактора учитывают отключение родительского UI.
- Смена слайда/макета сбрасывает окно текста. Выделение отбрасывает удалённые ID. Миниатюры сохраняют переключение, drag/drop и кнопки перемещения вверх/вниз.

## Буфер и структурные данные

Общий clipboard Context сохраняет объекты между вкладками; новые ID объектов/групп выделяются в документе назначения. Системные Copy/Cut/Paste и Ctrl+C/X/V/D поддержаны. Внешний plaintext создаёт текстовое поле; совпадающий текст внутреннего payload восстанавливает объекты. Кнопка вставки объектов использует внутренний буфер.

Пустые и неодинаковые строки таблиц остаются редактируемыми; структурные правки дополняют отсутствующие ячейки. Ячейки на холсте ограничены собственными границами; редактор ячеек прокручивается по двум осям и виртуализирует строки.

## Проверка

`cargo test --locked -p trinedocs slides::editor -- --nocapture`: 8/8 прошли, включая оба ранее падавших UI-теста и вставку между вкладками. Assertions выбора объекта и focus сохранены; дополнительно проверяется, что canvas находится внутри viewport. Тест заметок открывает панель перед запросом её focus. `rustfmt --edition 2024` выполнен через stdout и guarded write.

Реальные снимки окна, общий workspace test/clippy и интеграцию с AI-панелью проверяет root. Здесь они не заявлены завершёнными.

## Ограничения

Полный паритет PowerPoint не заявляется. Мастер-слайды, сложный rich text, SmartArt, crop/flip, мультимедиа, полноценный второй монитор докладчика и PPTX timing остаются в матрице паритета. Hit-test и рамки resize осевые для вращённых объектов. Текстовые свойства меняют первый выделенный объект. При совпадении внешнего текста с последним внутренним clipboard payload он трактуется как копия объектов. Narrator, контраст и реальные снимки Windows требуют отдельной проверки.
