Добавлены 20 регрессий: DOCX sdt, видимые drawing branches, header field results; HTML case/hidden; Markdown punctuation/комбинированные форматы/ссылки/manual breaks/heading inheritance/конечные пробелы; асимметричные поля, outdent/отключённый список, vMerge insert; очень высокий PNG; клавиатурные команды; пустой Copy, structured clipboard, group alignment/distribution, tiny charts. Некоторые тесты объединяют связанные варианты, число тестов не используется как число багов. Старое ожидание Heading3 для h4 в HTML-тесте исправлено на Heading4 в соответствии с уже принятой поддержкой h1–h6; это не новая production-причина.

Проверено статически: rustfmt этих шести Rust-файлов, git diff --check. Rust-регрессии добавлены, но не запускались. Build, cargo test/check/clippy, GUI, компилирующий CI и установщик не запускались.

Интернет-сверка: [CommonMark inline grammar и hard line breaks](https://spec.commonmark.org/0.30/) подтверждает escapes, вложенное выделение, ссылки и значение двух пробелов; это ориентир для исправленного подмножества, не заявление полного CommonMark/GFM. [Microsoft: VerticalMerge](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.verticalmerge?view=openxml-3.0.1) описывает продолжение вертикального объединения по одинаковым grid columns.

Ограничения: полный CommonMark/GFM (code spans/blocks, reference links, delimiter algorithm и сложные таблицы), HTML5 parser/CSS layout, revision UI и таблицы внутри content controls, сложные headers/footers и поля с live recalculation не реализованы данным пакетом. Непостраничные поля импортируются как cached visible text. Результаты OOXML/HTML/Markdown round-trip и точность вёрстки не считаются доказанными без будущего разрешённого запуска. PNG fit сохраняет данные, но полноценный crop/обтекание остаются отдельным объёмом.

Независимое итоговое чтение: App/inspector/MCP/package и иконка ведущего, а также четыре Sheets-файла прочитаны против 1782345. Статический блокер порядка borrow в новом Paste-вызове Sheets исправлен автором: координаты читаются до свободной функции с &mut Book. После перечитывания блокеров не осталось. Guard covered merge child инспектора и editor focus согласованы. PNG и SVG иконки просмотрены: белый фон и читаемый минималистичный знак; выполнение Windows shell не проверялось.

Взаимное ревью выявило край новой фичи: переход к объекту Slides внутри group выбирал только одного участника, после чего Align мог менять геометрию группы. request_focus теперь использует существующий select_object, выбирает всю группу и оставляет целевой элемент первым для scroll. Добавлена отдельная регрессия (18-я), без запуска; в 20 production-причин новая навигация не включена.

Ведущий при финальном чтении обнаружил квадратичный поиск malformed Markdown links в новой реализации. Это собственная регрессия текущего diff, не новый засчитанный дефект. Inline parsing теперь имеет общий для рекурсии бюджет: 16 × длина строки, от 4096 до 16 МиБ единиц работы. Поиск закрывающего разделителя идёт побайтно в пределах остатка бюджета и списывает реально просмотренный префикс; URL scan списывает только просмотренные символы до закрывающей скобки. При исчерпании остаток сохраняется буквальным текстом с inheritedformat. Entity scan ограничен 33 байтами. Добавлены регрессии длинных malformed links/амперсандов и 1000 коротких корректных bold/link-фрагментов, чтобы ограничение не отключало обычную разметку. Без запуска; худшее время ограничено бюджетом сканирования и линейным копированием текста. Избыточно сложная Markdown-разметка может остаться literal, её содержимое не отбрасывается.
