## Границы и известные ограничения

- PPTX всё ещё представляет только поддержанный поднабор Office. Первый непустой абзац/текстовый run задаёт единое оформление объекта; смешанные стили, bullets, сложные мастера и произвольные эффекты не объявляются реализованными.
- Наследуются поддержанные font size/bold/italic/font/color первого текстового контекста. Неравномерный/повёрнутый group transform, дополнительные текстовые направления и непрозрачные unsupported XML не получили полного round-trip.
- Равномерный group scale применяется к font/stroke и ограничивается текущими границами модели. Изображения с flipH/flipV декодируются с существующим pixel budget и нормализуются в PNG; исходное JPEG-сжатие не сохраняется.
- Rotation graphicFrame сохраняется в PPTX; поворот таблиц/диаграмм на холсте по-прежнему отключён. Общий Page/PDF пока не сохраняет поворот прочих объектов. Исправление mouse picking не является полной реализацией rotated resize handles или редактора повёрнутого текста.
- HTML — линейный документ с изображениями и поддержанным текстовым оформлением; не точная геометрическая копия слайда. Markdown — безопасный текстовый outline с изображениями, без полного визуального паритета. Встроенные PNG/JPEG используют data URI; ссылочные/сетевые изображения не загружаются.
- Разделы PPTX сохраняют названия и членство последовательных групп слайдов; исходные GUID разделов не являются ID внутренней модели. Другие extension types остаются ограничением.
- Расширение ragged table в PPTX ограничено 100000 плотных ячеек; допустимая разреженная модель может получить явную ошибку экспорта вместо разрастания XML.
- Сборка, cargo check, тесты, fmt/lint, Actions, приложение, Office и установщик не запускались. GUI/компиляция/Office interop остаются непроверенными.
