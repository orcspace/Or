## Пределы и приёмка

- Новые pages для Docs objects используют физические индексы ячеек, span сообщается отдельно. По умолчанию20 строк/64 ячейки на строку; максимум100/256. Для большой отдельной ячейки общий1 МиБ response limit сохраняется. Полный streaming rich-model read не добавлен.
- Sheets read_objects теперь применяет общий index/count независимо к коллекциям: default100, maximum100; totals доступны отдельно. Пагинация geometry является изменением ответа; потребители больших листов должны запрашивать следующие страницы.
- Alpha PNG уменьшается с сохранением PNG; точные размеры после уменьшения могут отличаться. Экспорт всех PNG ограничен256 МиБ в памяти; это не streaming export.
- Chat Markdown — ограниченный subset. Новый reset удаляет черновик при «Новый». Новые CLI/provider API не вводились.
- Завершённый export worker мог записать файл до отзыва разрешения; новая проверка блокирует stale response, не откатывает ранее разрешённую дисковую запись.
- Dry-run file tools проверяет базовые предусловия без записи. Корректный open_document по-прежнему требует UI flow. Пробные render/validation operations не запускаются.
- Keyboard, accessibility, runtime, Office/GUI rendering и компиляция требуют отдельной проверки.

Источники: [Windows naming](https://learn.microsoft.com/en-us/windows/win32/fileio/naming-a-file), [egui0.36.2 consume_key modifier behavior](https://docs.rs/egui/0.36.2/src/egui/input_state/mod.rs.html).
