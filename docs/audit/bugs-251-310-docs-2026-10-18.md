- After: Enforce a remaining-byte budget on every output append and each paragraph; preflight image Base64 allocation.
- Source: `crates/trinedocs/src/docs/io.rs`.
- Regression: `two_hundred_docs_io_regressions::html_export_stops_at_output_budget` (authored, not run).
- Limits: 32MiB production HTML budget; per-run and image fragments remain individually bounded by validated model limits.
