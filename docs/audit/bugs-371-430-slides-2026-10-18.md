## Проверка и ограничения

Работа только GitHub; исходники и Git локально не восстанавливались. Ни build/check/tests/fmt/lint/Actions, ни приложение, Office, installer, release или merge не запускались. Лексический просмотр скобок/строк и ручной review не доказывают компиляцию, UI/runtime, производительность или Office interoperability.

- Новые frames/layouts помещаются в геометрию маленького слайда, но это не полная реализация text autofit.
- Chart label font/size/emphasis теперь следуют модели. При недостатке места видимые подписи сокращаются по доступной ширине; полный текст и отсутствующие числовые категории остаются в модели и data/Office export. Числовой пропуск интерпретируется как0. Поддержан прежний единственный categorical series.
- PDF/Page выводит только целые видимые строки и glyph advances ячейки; точное clip частично видимых glyphs, повороты и сложный shaping остаются ограничениями общего renderer.
- GPU image cache ограничен4096 handles и32M pixel; измерения peak memory/FPS и компромиссы при cache thrashing не проверялись. Content hashes по-прежнему вычисляются из payload.

## Источники

- [egui IdTypeMap](https://docs.rs/egui/0.36.2/egui/util/id_type_map/struct.IdTypeMap.html): temporary values живут до завершения Context; большие значения рекомендовано хранить через Arc.

- Timing import сохраняет представимые click/with/after_previous offsets и миллисекундные durations. Interactive/event-driven triggers, nonlinear paths, pacing, arbitrary behaviours and repeatCount remain outside the native animation model. Curves/multiple segments are approximated by endpoint and flagged.
- Motion path number parsing is streaming; unsupported/malformed commands are skipped rather than allocated as an unbounded token list.
- Pulse PPTX uses a full-duration three-keyframe size envelope; exact easing/Office playback remains unverified.

Дополнительные первичные источники:
- [OOXML AnimateMotion](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.presentation.animatemotion?view=openxml-3.0.1): uppercase commands use absolute coordinates; lowercase commands use relative coordinates.
- [OOXML CommonTimeNode](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.presentation.commontimenode?view=openxml-3.0.1): duration, start conditions and boolean autoRev.

- Presenter input/transition changes are source-reviewed only; no interactive keyboard/pen or fullscreen timing run was performed. Outgoing transitions freeze the state captured at navigation, preserving partially completed effects.
- Table Office font export follows native row-constrained size down to the OOXML1pt minimum; smaller native rendered sizes remain an interchange limit. Text insets are explicit, but complex typography/shaping parity remains unverified.
- JSON serialization is bounded during emission, including decimal image arrays. Oversized JSON/PPTX cache output returns an error; native asset-based save remains the alternative. No peak-memory measurements were run.

- [OOXML FontReference](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.fontreference?view=openxml-3.0.1): explicit themed font selection.
- [OOXML FillReference](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.fillreference?view=openxml-3.0.1): indexes0 and1000 mean no fill.
- [OOXML BodyProperties.LeftInset](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.bodyproperties.leftinset?view=openxml-3.0.1): omitted inset implies91440EMU, different from native5pt.
