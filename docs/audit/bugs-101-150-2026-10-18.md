## Объём и ограничения

- Это исправления кода по статическому review. Все 50 целевых регрессий написаны, но не запускались; компиляция, runtime, GUI/AccessKit, измерения памяти/времени и Office round-trip не подтверждены.
- Markdown: поддержан ограниченный набор CommonMark/GFM, полного парсера/паритета нет. Внешние soft line breaks теперь объединяются; собственный маркер v2 сохраняет прежние физические границы абзацев и пустые абзацы. Старые внешние файлы без маркера могут получить другую структуру абзацев.
- Markdown images: только встроенные PNG/JPEG data URI, без сети/относительных файлов; размер при импорте определяется по пикселям, произвольный display size не сохраняется. Лимит экспорта64 МиБ; таблицы до10000 строк/256 столбцов/100000 ячеек, остаток сверх лимита импортируется текстом с loss notice; общие лимиты модели проверяются дополнительно.
- Sheets HTML: таблицы/merges, поддерживаемое текстовое оформление и размеры; изображения после таблицы с подписью адреса, без точного floating placement. Диаграммы и полное conditional formatting не включены. Лимиты100000 ячеек на лист,1000000 на книгу и64 МиБ вывода.
- Find Docs ищет основной текст, не таблицы. Bulk replace:100000 совпадений,16 МиБ совокупного текста,100000 абзацев плюс validate; прежний API usize сохраняется, checked API возвращает ошибку.
- Финансовая численная стабилизация PMT/PV ограничена положительной ставкой/сроком с большим ростом. Wildcard SEARCH сохраняет прежний алгоритм; ускорен только literal SEARCH.
- PPTX noFill для Rect/Ellipse хранится отдельно от RGB и контура; это не поддержка всех fill/effect типов DrawingML. Старые нативные модели получают fill_visible=true через serde default.
