# Минималистичный интерфейс06

Основа: PR8, `5078a6d`; ветка `codex/minimal-ui-06`. Реализована общая рестилизация оболочки и трёх редакторов. Это UI-пакет по последнему запросу владельца; визуальные изменения не объявляются50 исправленными багами или приёмкой полного Office parity.

| Поверхность | Что изменилось |
|---|---|
| Общие элементы | Нейтральные светлые/тёмные поверхности, тонкие разделители, меньше постоянных рамок и теней; Body14/Button13, основные hit areas28px. Акценты редакторов определены общими tokens. Focus stroke остаётся выраженным. |
| Верхняя панель | Спокойный wordmark, векторные Save/Close, настройки темы в меню, постоянная кнопка ассистента и поиск команд. Действия File/Open/Save/Undo/Redo доступны по прежним маршрутам. |
| Вкладки документов | Плоская поверхность активной вкладки и тонкое подчёркивание. Название ограничено200px и truncate, полный путь остаётся в tooltip. Dirty marker рисуется отдельно от обрезаемого названия, Close остаётся видимой кнопкой. |
| Главная | Плоские104px карточки создания вместо больших декоративных preview, компактный вступительный текст, спокойные значки и более свободные строки файлов. Меню ··· постоянно доступно; закрепление/удаление из списка доступны через него. Неверная подсказка о ☆ заменена. |
| Docs | Одна строка quick format/insert/view, именованные меню подробных параметров и стилей. Убрана декоративная тень страниц. Возврат к вводу закрывает toolbar popup; stable cell/canvas/widget IDs сохранены. |
| Sheets | Одна строка команд, числовые/вторичные параметры в меню, согласованная строка адреса и формул с focus underline, плоские sheet tabs и спокойная сетка. Хранимое оформление ячеек не меняется. |
| Slides | Компактные command bars, меньше рамок миниатюр, единая поверхность боковых панелей, раскрываемые свойства/переходы вместо постоянно развёрнутых блоков. |
| Ассистент | Единая шапка с Close, ограниченная ширина панели, история заданий скрыта при пустом списке. Chat получил спокойные сообщения/композер, видимые provider/model/depth и отдельную кнопку Stop. Технические события сгруппированы в раскрытия. |
| Статус | Короткие состояния saving/unsaved/new/saved/read-only/lock; длинный текущий статус обрезается с полной подсказкой. Ошибки/подтверждения и активные AI-job cancellation controls сохранены. |

Подробности и независимые ревью: [Docs/Slides](minimal-ui-06-editors.md), [Sheets/Chat](minimal-ui-06-sheets-chat.md). Два агента перекрёстно перечитали соседние редакторы и root App/chrome. Закрыты замечания truncate/dirty marker, pinned hint и точности подписи MCP-off. Методы запуска/авторизации/парсинга Chat не менялись; model/ops/io и форматы сохранения не изменялись.

Документация shortcuts уточнена по реальной реализации: AI-панель Ctrl+Shift+A; Ctrl+J остаётся Docs Justify. Привязки клавиш в production не менялись. Существующие chrome APIs сохранены; новых зависимостей/шрифтов/растровых ассетов нет.

Статические проверки прошли: `cargo fmt --all -- --check`, `git diff --check`, `python -B tools/spec_registry.py check` (442REQ/361PAR), `python -B tools/check_assets.py`. Для чистой рестилизации новые parity-возможности не добавлялись. Проверены локальные API egui0.36.2 (widgets focus, Button::truncate, menus/popups, ComboBox, TextEdit, Frame). Сравнение toolbar action sites не выявило удаления прежних содержательных команд; смена названий «Новый чат»/«Стоп» и «+» не меняет callbacks.

Расчёт номинального sRGB-контраста основных tokens: светлая тема text/surface15.01:1, muted/surface5.47:1, muted/workspace4.92:1; тёмная text/surface12.45:1, muted/surface6.62:1. Это расчёт восьми пар tokens, **не** доказательство полной WCAG/accessibility-приёмки: фактические состояния, ОС high contrast, document content, keyboard/Narrator и масштабирование отдельно не проверены.

**Сборки, cargo check/test/clippy, запуск приложения/GUI, регрессии, скриншоты приложения, установщики и релизы не выполнялись.** По запрету владельца типизация, runtime focus, реальное narrow-window поведение и визуальное качество ещё не подтверждены. Горизонтальная прокрутка поддерживает команды на узкой ширине; многоуровневые popups/длинные локализованные строки и несколько одновременно открытых панелей требуют разрешённого последующего запуска. Полная Office parity и прочие GAP сохраняются.

Первичные источники сверены16.10.2026: [Fluent2 Layout](https://fluent2.microsoft.design/layout), [Fluent2 Typography](https://fluent2.microsoft.design/typography), [Fluent2 Toolbar](https://fluent2.microsoft.design/components/web/react/core/toolbar/usage), [Windows Command bar](https://learn.microsoft.com/en-us/windows/apps/design/controls/command-bar). Применены общая визуальная иерархия и разделение частых/вторичных команд; реализован собственный native egui UI.
