# Минималистичный UI06 — Sheets и Chat

Основа:5078a6d. Область изменений: только sheets/editor.rs и UI-методы model_row/show_panel в chat.rs. Этот пакет — рестилизация и перегруппировка существующих команд, не50 исправленных production багов и не приёмка полного Office parity.

Sheets: постоянная лента стала одной строкой с горизонтальной прокруткой на узкой ширине. Вставка, шрифт/размер и B/I/U доступны сразу; буфер, вторичный формат, выравнивание/merge и числовые форматы — в именованных меню. На вкладках Вставка/Данные/Вид остались все прежние команды: оформление диапазона, семь видов диаграмм, изображение, лист/строки/столбцы, сортировка/заполнение/поиск/пересчёт, закрепление/размеры/видимость. Сохранены прежние command_action/commit/error guards и реальные callback операций.

Строка адреса и формул получила общий ритм и тонкую нижнюю линию; активное поле имеет выраженный focus underline. IDs location/formula/canvas, обработка Enter/Tab/Escape и незавершённого ввода сохранены. Сетка визуально тише; записанное оформление и границы ячеек не меняются. Вкладки листов стали плоскими с активным подчёркиванием; контекстные команды и статистика диапазона сохранены.

Chat: компактная шапка с провайдерами, видимыми моделью/глубиной и действием Новый; custom model/login/status refresh доступны в параметрах. Число рамок и декоративных символов сокращено; ответы имеют тихую подпись Ассистент, ошибки и подсказки входа остаются в основном потоке. Последовательные технические tool events собраны в раскрываемые Действия с количеством и исходным именем инструмента в tooltip. Многострочные системные инструкции не сворачиваются.

Контекст документа/выделения расположен над полем сообщения. Отправить/Остановить находится в отдельной нижней строке и не конкурирует с длинным названием документа. Передача выделения, retry, copy, clear, provider/model/effort/options и горячие клавиши остаются доступны. При выключенном MCP отображается состояние доступа к документам. Соли chat-model/chat-effort/chat-input/chat-messages сохранены; новые раскрытия имеют собственный ID по индексу сообщения. Lifecycle/launch/auth/parser/ops не изменены.

Первичные рекомендации сверены2026-10-16: [Fluent2 Toolbar](https://fluent2.microsoft.design/components/web/react/core/toolbar/usage), [Windows Command bar](https://learn.microsoft.com/en-us/windows/apps/design/controls/command-bar). Применены различие основных/вторичных действий и текстовые названия меню; egui API ComboBox::truncate, TextEdit::frame и CollapsingHeader::id_salt сверены по локальному0.36.2. Стек, зависимости и ассеты не менялись.

Проверка: rustfmt --edition2024 --check двух файлов и git diff --check прошли. Дифф Chat проверен на отсутствие изменений за пределами двух UI-методов; ни один путь изменения документа не заменён. Тесты, сборка, cargo check/clippy, запуск приложения/GUI, CI и установщик не выполнялись. Визуальная приёмка, реальные narrow-width layouts, screen-reader поведение и runtime focus требуют последующего разрешённого запуска.
