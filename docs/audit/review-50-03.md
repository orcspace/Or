# Пакет 03 — 50 исправлений, переходы к замечаниям и новая иконка

Основа — `1782345` / PR #5. Ветка `codex/review-50-ui-03`; отдельный PR поверх предыдущего пакета. Работа продолжается до команды владельца «стоп».

50 самостоятельных причин: [20 Sheets](review-50-03-core.md), [20 Docs/Slides](review-50-03-editors.md), [10 оболочка/MCP](review-50-03-shell.md). Несколько проявлений одного корня сгруппированы; навигация и бренд не считаются багами.

Главные исправления: расчёты и ссылки Sheets, скрытые/объединённые ячейки и закреплённые области, Markdown/HTML/DOCX сохранность текста и форматирования, clipboard и группы Slides. MCP корректно пересчитывает массовые замены, применяет тему/макет, не выдаёт старую undo-группу за новую и возвращает доступное описание слайда с картинками. Восстановление сохраняет незавершённый ввод.

Замечания проверки документа теперь кликабельны: абзац/якорь картинки Docs, существующая видимая ячейка Sheets, объект Slides. Перед переходом проверяются stable ID и версия. Устаревшие, скрытые и covered merged-cell цели отключены. Навигация не создаёт undo. Область самих эвристик инспектора остаётся прежней и неполной.

[Новая иконка](../design/trinedocs-icon-2026-10.md): белый фон, три связанных листа в цветах редакторов. Векторный мастер, PNG256 и ICO с девятью размерами. PNG просмотрен; размер, непрозрачный белый фон, заголовок/смещения/все PNG-кадры ICO проверены без сборки. Существующие потребители PNG/ICO сохранены.

Добавленные Rust-регрессии **не запускались**. Пройдены статические проверки: cargo fmt --all -- --check, git diff --check, реестр требований 442 REQ / 359 PAR и assets. Сборка, cargo test/check/clippy, GUI, MCP/runtime smoke, performance, установщик, компилирующий CI и релиз не выполнялись. Коммит с `[skip ci]`; предыдущие PR не сливаются автоматически.

Интернет-сверка включена в тематические отчёты: первичные Microsoft источники по Excel/OOXML и иконкам, W3C XML1.0 и CommonMark. Эти документы подтверждают ожидаемое поведение, но не заменяют запуск приложения.

Полный Office parity, сложный HTML/CommonMark, поля с live пересчётом, сложная вёрстка и OOXML round-trip остаются неполными; точность эвристик Slides оценочная. [План](../plan/phase-review-50-03.md).

Новое направление владельца: следующие изменения усиливают ИИ для одновременной работы с несколькими открытыми Docs/Sheets/Slides. Актуальная [MCP tools specification](https://modelcontextprotocol.io/specification/2026-07-28/server/tools) сверена; многодокументные операции и фоновые задания будут отдельным пакетом, а не объявляются готовыми этим отчётом.

Два независимых агента прочитали редакторы и интеграцию ведущего; ведущий отдельно прочитал оба набора. Найденные в новых изменениях borrow-ошибка Paste, одиночное выделение члена группы и край бюджета Markdown исправлены до публикации, в 50 не засчитывались. Старый inspector fixture переведён с set_input на set_cell для фактического расчёта Value; тест не запускался и новой production-причиной не считается.
