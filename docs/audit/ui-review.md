# UI и доступное редактирование — два прохода ревью

Запрос владельца 2026-10-13: приятный интерфейс примерно как Word, доступные таблицы и правка, lock-файлы и MCP. Работали root и три агента, с path claims и guarded writes.

Первый проход: каждому редактору добавлена лента реальных команд, Root — общая светлая палитра, домашние карточки, заголовок и вкладки. Docs сохраняет один центрированный столбец страниц; таблицы/изображения имеют отдельные редакторы. Sheets сохраняет виртуальную сетку и диаграмму; Slides — миниатюры, холст, свойства и компактные окна.

Второй проход: агенты перекрёстно проверили другие редакторы и root-файлы. Найдены и исправляются реальные ошибки: поиск без фокуса, изменение постороннего выделения при Replace, commit формулы внутри TextEdit, старое значение при Ctrl+S, focus холста слайдов, копирование между вкладками, геометрия закреплённых merge, переполнение узкого окна. Результаты целевых и общих regression tests фиксируются после выполнения; тесты не заменяют чистую VM и полную приёмку Office.

Root: save_locked отделён от read_only. Чужой marker не отключает UI/MCP/undo; занятый исходный файл не перезаписывается, есть сохранение копии и явная проверка/снятие оставшегося marker. Живой Windows marker удерживается открытым handle с запретом write/delete. Takeover сравнивает preview bytes; stamp проверяется до и после экспорта. Текстовые .lock открываются и сохраняются как TXT. Это не изменение бинарных/служебных форматов.

Подтверждение стало настоящим Modal; pending не перезаписывается ответом UnlockPreview/RegistrationPreview/PickedSave. Выбор сохранения занимает per-tab picking state и блокирует параллельный MCP-save/закрытие; открытый picker также предотвращает зависание закрытия. Save/Close/Undo/Redo выполняются после обработки ввода текущего кадра. Sheets draft коммитится перед snapshot/close/MCP writes, invalid draft не стирается. MCP возвращает save_locked/read_only и конкретные file_locked/busy/needs_path ошибки.

Предыдущие два больших ревью: release-review.md и review-2-*.md; текущие детальные отчёты: ui-docs-review.md, ui-sheets-review.md, ui-slides-review.md.

Известные ограничения остаются: полный паритет Office, inline edit/merge таблиц Docs, произвольные семейства системных шрифтов на canvas/PDF, advanced Sheets, полноценный presenter/masters/timing, потоковый AI cursor/notifications. Это preview, а не заявление о готовности всех функций.

Уточнение минимализма: постоянные команды редакторов сокращены, расширенные действия доступны в меню; убраны лишние рамки и дублирование названия файла. Переключение на вкладку/Главную и закрытие крестиком отложены до обработки ввода текущего кадра, как Ctrl+Tab/Ctrl+W. Это закрывает пропуск последнего ввода перед переключением или проверкой dirty.

Дополнительное ревью минимальной компоновки: общий horizontal ribbon наследовал всю доступную высоту, его разделители уводили Docs canvas и Sheets formula field за viewport. Высота command ScrollArea ограничена; добавлены проверки реальной геометрии ribbon, formula field и slide canvas. Палитра делит события на prefix/tail: ранее набранное остаётся документу, ввод после хоткея получает поиск. Docs и Sheets custom handlers явно проверяют enabled; Text/Paste/Delete/Cut больше не обходят отключённый UI. Проверки добавлены, общий итог фиксируется после запуска.
