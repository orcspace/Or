В текущем изменении: фильтр недавних/закреплённых файлов по Docs/Sheets/Slides; очистка поиска; выбор команды стрелками с запуском по Enter; сокращение длинных вкладок с полным путём в подсказке; перенос строки статуса; правильный статус страницы Docs.
