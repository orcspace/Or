## BUG-311 — COUNT/COUNTA prematurely propagate computed errors

- Before: COUNT(1/0) and COUNTA(1/0) return #DIV/0!, unlike equivalent error values in cells.
- After: Evaluate computed errors as argument values for these two counting functions; counts become0 and1.
- Path: [crates/trinedocs/src/sheets/formula.rs](../../crates/trinedocs/src/sheets/formula.rs).
- Regression: `count_functions_classify_computed_errors_as_values`; written, not run.
- Limits/evidence: Microsoft COUNT/COUNTA error-value classification; no changes to SUM propagation.
