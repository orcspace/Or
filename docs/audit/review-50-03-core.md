# Пакет 03 — независимое ревью Sheets

База: `1782345`. Проверены Sheets model/formula/editor и существующие регрессии. **20 новых причин**, по одной строке на общую причину; варианты функций и осей повторно не считаются. Навигация из проверки документа — дополнительная фича, в 20 не входит.

| ID | P | Сценарий до изменения | Причина и исправление |
|---|---|---|---|
| C3-01 | P1 | Текст `Other!A1` менялся на `#REF!` при удалении Other. | delete_sheet переписывал все input, включая обычный текст. Обновляются только формулы. |
| C3-02 | P1 | Сортировка строк 3, 1 (hidden), 2 переносила скрытую строку и её данные. | В список сортировки попадали все позиции. Сортируются только видимые строки; hidden сохраняют позицию и cell ID. |
| C3-03 | P1 | Named range `Cell=A2`: ROW/COLUMN/ISFORMULA теряли идентичность ссылки, SUBTOTAL по имени не исключал вложенные итоги/hidden rows. | Функции распознавали только прямой Expr::Reference. Общее разрешение имён сохраняет target/range, проверяет отсутствующий лист и ограничивает цепочку. |
| C3-04 | P1 | SUBTOTAL(3,A1:A3) пропускал обычный текст `SUBTOTAL(`, считая его вложенным итогом. | Подстрочная эвристика заменена разбором AST только формул; quoted text внутри формулы не считается вызовом. |
| C3-05 | P1 | COUNTIF(A1:A3,Z1) с пустой Z1 искал пустой текст вместо числового 0. | Пустой criteria-reference приводится к 0; явный критерий `""` продолжает искать пустые значения. |
| C3-06 | P1 | POWER(0,0) / 0^0 возвращали 1; POWER(0,-1) — #NUM!. | IEEE powf не повторяет Office domains. Общий helper возвращает соответственно #NUM! и #DIV/0!, конечность остальных результатов проверяется. |
| C3-07 | P1 | MATCH(2,{1;2;2},1) и approximate VLOOKUP возвращали первый дубликат вместо последнего. | Ранний выход при equality. Exact MATCH/XMATCH продолжают выбирать первое совпадение; approximate MATCH/VLOOKUP учитывают последнюю равную позицию. |
| C3-08 | P1 | Approximate MATCH/VLOOKUP/XLOOKUP искали текстовый ключ в числах через общий порядок типов и возвращали число. | Кандидаты approximate matching проверяются на совместимый тип lookup value; exact-mode поведение сохраняется. |
| C3-09 | P1 | Arrow/Enter/Tab ставили активную ячейку в скрытую строку или столбец. | Простая арифметика координат заменена шагом с пропуском hidden axes и сохранением позиции при достижении края. |
| C3-10 | P1 | Из A1:C3 Enter/Tab переходили в невидимые B1/A2 внутри того же merge. | Шаг выходит за границу текущего merge; при входе в другой merge выбирается его anchor. |
| C3-11 | P2 | При малом scroll и закреплении одни frozen cells рисовались повторно; заливка/выделение усиливались. | Пересекающиеся диапазоны chain заменены уникальным набором; обычные клетки рисуются перед закреплёнными. |
| C3-12 | P1 | После scroll закреплённые клетки оставались, но их row/column headers уезжали либо исчезали. | Заголовки используют тот же frozen transform и отдельный видимый набор осей, что клетки. |
| C3-13 | P1 | Большой merge пересекал viewport, но текст/фон исчезали, когда верхняя левая клетка оказывалась за экраном. | Anchor добавляется по пересечению всей merged area, а не только видимой исходной клетки. |
| C3-14 | P1 | В UI ввод `001` в Text-format ячейку становился Number(1); `=1+1` вычислялся. | Типизированный и pasted UI input учитывает `@` и сохраняется как literal через существующий апостроф. Уже введённые значения не переконвертируются при изменении формата. |
| C3-15 | P1 | Начать file-image на Sheet1!D4, перейти на Sheet2!J10 до завершения: картинка появлялась в новой позиции. | Pending job хранит исходные sheet ID/row/col. Удалённый лист даёт ошибку; картинка другого листа не становится selected_image текущего листа. |
| C3-16 | P1 | Delete на пустом большом выделении создавал до 100 000 cell objects и расширял used range. | UI clear использует существующий sparse clear_range: удаляет только содержимое, сохраняет форматы и существующие ID форматированных клеток. |
| C3-17 | P1 | Merge A1:AX1500 или картинка с дальним anchor/большим offset выходили за доступную прокрутку пустого листа. | Размер canvas учитывает merged bounds и правую/нижнюю границу floating images; cell used range для экспорта не раздувается. |
| C3-18 | P1 | TIMEVALUE("6:45 PM") возвращал #VALUE! вместо доли суток. | Разбор AM/PM с переводом 12 AM / 12 PM, нормализацией пробелов/регистра и проверкой границ; 24-часовой ввод сохраняется. |
| C3-19 | P1 | Multi-cell paste поверх merge записывал данные в covered cells, которые canvas не отображает. | set_range проверяет пересечение с merge до любых записей и отклоняет несовместимую вставку целиком. Одно значение в anchor разрешено; запись в covered child отклонена. |
| C3-20 | P1 | AutoFit измерял число 1 с форматом `0.000000000000` как один символ и игнорировал font size; короткий текст не сужал колонку. | Измеряется готовый display text с текущим egui family/size/style; merged cells пропускаются, ширина ограничена допустимыми размерами модели. |

Добавлены **16 Rust-регрессий**: 7 в sheets/tests.rs и 9 в editor.rs. Проверяются literal preservation, named references, AST SUBTOTAL, blank criteria, domains, duplicate/type lookup, hidden-row sorting, hidden/merged keyboard targets, frozen coordinates/уникальность, offscreen merge, Text input, sparse clear, geometry, AutoFit, asynchronous image target и read-only focus requests. Они **не запускались**. Rustfmt разобрал все четыре изменённых Rust-файла; rustfmt --check и git diff --check для Sheets прошли. Сборки, cargo test/check/clippy, GUI, установщики и компилирующий CI не запускались.

Переход из проверки принимает только существующую клетку на видимом листе/оси вне covered merge child, не заменяет незавершённый draft и запрашивает scroll. Запрос потребляется также в read-only, фокус ввода там не захватывается. Это интеграция нового inspector UI, отдельно от счёта багов.

Первичные источники: [Microsoft: сортировка hidden rows](https://support.microsoft.com/en-us/excel/sort-data-in-a-range-or-table-in-excel), [SUBTOTAL и named references](https://support.microsoft.com/en-us/excel/functions/subtotal-function), [TIMEVALUE, AM/PM](https://support.microsoft.com/en-us/excel/functions/timevalue-function), [MS-OI29500 POWER(0,0)](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oi29500/a2ea85f8-876e-4587-9580-08fc856b67ab), [ввод в Text-format](https://support.microsoft.com/en-gb/excel/enter-data-manually-in-worksheet-cells), [содержимое merged cells](https://support.microsoft.com/en-us/excel/get-started/merge-and-unmerge-cells-in-excel). Источники используются для конкретной семантики, не как свидетельство runtime-приёмки.

Ограничения: TIMEVALUE пока не принимает дату перед временем/дробные секунды и не покрывает все locale time formats. Approximate lookup предполагает корректно отсортированные исходные диапазоны; полная бинарная стратегия не заявляется. SUMIF named sum_range projection, полноценные filtered-row metadata, Ctrl+Arrow/Home/End/Page navigation через все hidden/merged комбинации, nested merge clipping на границах frozen panes, произвольный rich clipboard и полный Office parity остаются отдельным объёмом. При первой загрузке custom font AutoFit использует текущий доступный fallback face, как canvas; точное соответствие после регистрации шрифта требует повторения команды. Multi-cell merged paste отклоняется с понятной ошибкой; автоматическое разбиение/копирование геометрии merge не реализовано. UI underline+strike по-прежнему требует отдельного исправления; прошлый пакет исправил обе линии в PDF, а не этот canvas branch. Ничего из перечисленного не включено в 20 исправлений.

Взаимное независимое чтение: прочитаны полные production diff шести Docs/Slides файлов (editor/model/io) и четырёх файлов ведущего (app, inspector, package, mcp/tools). Проверены ненулевой chart_bounds, сохранение vMerge, positive geometry fitted image, Markdown escaping/наследование/ссылки, cached header fields, request-focus IDs, сохранение recovery draft, асинхронный watcher stamp, ZIP XML scalars и MCP recalc/theme/layout/no-op response. Блокеров в текущих исходниках ведущего не обнаружено. Редакторский ревьюер обнаружил borrow-проблему нового свободного paste_values(book, ... book.selection ...): координаты теперь читаются в locals до заимствования &mut Book; повторный rustfmt/check-format прошёл. Эта промежуточная ошибка не считается дополнительным исправленным багом. Переход инспектора к Slides group member перепроверен после исправления через select_object: выбирается группа, requested member становится первым для scroll. Перепроверена защита нового Markdown parser от повторных поисков: shared budget теперь списывает реально просмотренные байты, URL scan завершается по остатку бюджета, entity scan ограничен 33 байтами. Промежуточное списание полной длины хвоста отвергнуто ревью, поскольку оно ломало длинную строку коротких валидных выделений/ссылок; добавлена регрессия на 1000 таких сегментов, не запускалась. Финальные production изменения Docs/Slides после этих уточнений прочитаны без оставшихся блокеров; rustfmt --check и diff-check для последних двух файлов прошли. Типизация и runtime не подтверждались.
