S4-07 отличается от Unicode lookup в formula.rs: здесь исправлен путь изменения словаря MCP, там — чтение/вычисление ссылок. S4-09 и S4-10 имеют разные причины: UI I/O и общий изменяемый файл между процессами.

Новая функция вне квоты: workspace_documents/apply/job_status/cancel. Подготовка разных моделей идёт параллельно, commit через ops в UI проверяет все исходные версии и права перед изменением первого документа. До4 документов и32 операций, до4 одновременных заданий, таймаут60с, до64 записей истории в памяти. Ошибка/конфликт/отмена до commit не применяет пакет. На каждый изменённый документ одна авторская undo-группа. Пакет не меняет активную вкладку. Индикатор и отмена доступны в оболочке; история заданий — в AI панели.

Это пользовательские MCP tools с явным job handle, не реализация протокольного Tasks extension. Полный apply_ops любых типов из REQ-M06-072 не заявлен: файлы/печать/сеть/undo/создание и nested jobs исключены. Crash-atomic транзакция нескольких файлов, сохранение заданий после перезапуска, повторное подключение внешнего клиента с новой сессией и измерения памяти/задержки остаются GAP. Внешний клиент видит только задания своей MCP-сессии; собственный чат — своего launch nonce.

[Первичный источник MCP Tools](https://modelcontextprotocol.io/specification/2026-07-28/server/tools): схемы, structured results, ошибки и индикаторы вызовов. Сверен15.10.2026. Действующая точная версия rmcp3.5.0 и её локальные API прочитаны; зависимости не добавлялись.
