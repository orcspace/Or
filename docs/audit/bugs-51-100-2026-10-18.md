## Границы

HTML остаётся ограниченным импортом, без браузерного CSS cascade, HSL/alpha, полного набора entities и восстановления любого повреждённого HTML. Изображения внутри абзаца якорятся после него. DOCX shading patterns, сложные скрипты, first/even headers и полная совместимость Word не заявляются. XLSX multiple selections и activeCell внутри прямоугольника не полностью представимы моделью: сохраняется активная ячейка, полный прямоугольник восстанавливается для углового activeCell. Форматирование графиков и произвольные межлистовые серии остаются прежними ограничениями. UI не запускался: адаптация к ширине и доступность требуют ручной проверки после разрешения запусков.
