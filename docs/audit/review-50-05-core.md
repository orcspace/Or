# Пакет 05 — независимое ревью Sheets

База `8e6c20b` (follow-up PR #7). **20 новых production причин**; повторения функций/осей сгруппированы. Исправления прошлых пакетов и собственные промежуточные ошибки в счёт не входят.

| ID | P | Дефект до изменения | Исправление |
|---|---|---|---|
| C5-01 | P1 | В en-книге VALUE("1,000") давал 1; официальный пример VALUE("$1,000") и время 16:48 отвергались. | VALUE отдельно разбирает числовую локаль, валютный/accounting ввод и поддержанные числовые даты/время. NUMBERVALUE не получает валютных правил. |
| C5-02 | P1 | CHAR(128) возвращал управляющий Unicode символ вместо € в en; CODE("А") — 1040 вместо ANSI-кода 192 в ru. | Отдельный ANSI ru/en путь через уже имеющийся encoding_rs. UNICHAR/UNICODE сохраняют Unicode scalar semantics. |
| C5-03 | P1 | WORKDAY(2,200000) и NETWORKDAYS(2,1400002) давали #NUM! из-за произвольных 100000/1000000 лимитов. | Число полных недель + максимум 6 дней, дедупликация праздников; WORKDAY ищет дату двоичным поиском в допустимом домене. |
| C5-04 | P1 | Отрицательный/out-of-domain числовой праздник silently игнорировался даже при корректных start/end. | Даты и праздники проходят проверку допустимых serial dates до календарного вычисления; некорректный date input даёт Office #VALUE!, выход результата WORKDAY за домен — #NUM!. |
| C5-05 | P1 | PMT/PV/FV/NPER/IPMT/PPMT с rate=1e-20 теряли нулевой предел из-за 1+rate и growth−1. | Общие growth/annuity используют ln_1p/exp_m1; NPER считает логарифм изменения отношения. RATE использует те же устойчивые компоненты. |
| C5-06 | P1 | IRR([-1e308,1e308,1e308]) мог сообщать guess=0.1 как корень: промежуточная производная переполнялась. | Все cash flows нормализуются одним масштабом до Newton step; масштабирование не меняет корень. |
| C5-07 | P1 | GCD отвергал допустимый аргумент 9005000000000000, а LCM мог вернуть результат ≥2^53. | Общий точный целочисленный домен [0,2^53), проверка конечного integer result. |
| C5-08 | P2 | Формат #0.0E+0 для 12200000 показывал 1.2E+7 вместо официального 12.2E+6; встроенный ##0.0E+0 тоже терял engineering grouping. | Число целых placeholders управляет группой exponent; округление переносится на следующую группу. |
| C5-09 | P2 | # ?/8 выводил сокращённую дробь вместо фиксированного знаменателя; ?/?? добавлял целую часть вместо improper numerator. | Разбор fixed/variable denominator и наличия mixed-integer части; до 3 variable denominator placeholders. |
| C5-10 | P1 | Имя листа с LF/TAB/C0 принималось и затем мешало безопасному XLSX сохранению. | Control characters отклоняются при add/rename и validate, до изменения модели. |
| C5-11 | P1 | Заполнение пустым источником создавало множество пустых ячеек, расширяло used range и расходовало лимит cell objects. | Default empty fill удаляет только записи назначения; отсутствующие клетки не материализуются. |
| C5-12 | P1 | Ctrl+D/R или sheets_fill записывали в covered merge children невидимые данные; защита set_range этот путь не охватывала. | Fill preflight отвергает затрагивание merge целиком; одиночная запись в anchor разрешена. Ошибка атомарна. |
| C5-13 | P1 | Ctrl+Arrow/Home/End/Page могли оставлять selection на hidden axes или внутри covered merge child, хотя обычные стрелки были исправлены раньше. | Data-edge считает только видимые позиции; все jump targets проходят visible/merge canonicalization. |
| C5-14 | P1 | После переключения листа selected_image сохранял ID картинки прежнего листа; Delete выдавал «рисунок не найден» вместо удаления нового выделения. | При смене sheet ID сбрасывается прежний selected_image. Pending image import по-прежнему хранит исходный target. |

| C5-18 | P1 | rel:id/alias:embed с корректным relationship namespace теряли styles/metadata/pictures, поскольку код ожидал literal r:id/r:embed. | NsReader разрешает relationship attributes по URI и сохраняет стек namespace scope. |
| C5-19 | P1 | Charts шириной/высотой 1–79px экспортировались минимум 80px, хотя модель и writer разрешают такие размеры. | Экспорт ограничивает размер модельным диапазоном 1–4000px, округляет до пикселя. |
| C5-20 | P1 | Текст ячейки *literal*, [link](...), <b> или &name превращался в Markdown markup/HTML вместо исходного текста. | Markdown escaping для punctuation и HTML entities; нормализация CR/LF, созданный <br> сохраняет перенос. |

Дополнительно, **вне счёта 20**, HTML td получил white-space:pre-wrap, сохраняющий переводы строк и повторные пробелы.

Добавлено **15 Rust-регрессий**: 8 model/formula, 2 editor, 2 format, 3 IO. Они **не запускались**. Прочитаны локальные API encoding_rs, quick-xml 0.42.0 NsReader/NamespaceResolver, rust_xlsxwriter chart width/height. `rustfmt --edition 2024 --check` для шести файлов и `git diff --check` прошли. Сборки, cargo test/check/clippy, приложение, GUI, CI и установщики не запускались. Типизация и runtime не подтверждены.

Первичные источники сверены 2026-10-16: [VALUE и currency/time пример](https://support.microsoft.com/en-us/excel/functions/value-function), [CHAR Windows ANSI](https://support.microsoft.com/en-us/excel/functions/char-function), [CODE](https://support.microsoft.com/en-us/excel/functions/code-function), [WORKDAY](https://support.microsoft.com/en-us/excel/functions/workday-function), [NETWORKDAYS](https://support.microsoft.com/en-us/excel/functions/networkdays-function), [GCD домен](https://support.microsoft.com/en-us/excel/functions/gcd-function), [LCM](https://support.microsoft.com/en-us/excel/functions/lcm-function), [IRR](https://support.microsoft.com/en-us/excel/functions/irr-function), [числовые форматы: scientific/fractions](https://support.microsoft.com/en-us/excel/review-guidelines-for-customizing-a-number-format), [indexedColours](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.indexedcolors?view=openxml-3.0.1), [PatternFill](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.patternfill?view=openxml-3.0.1), [LeftBorder](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.leftborder?view=openxml-3.0.1), [XML namespace identity](https://www.w3.org/TR/xml-names/#ns-qualnames), [CommonMark escapes](https://spec.commonmark.org/0.31.2/#backslash-escapes).

Ограничения: ANSI выбирается по локали книги (ru CP1251, en CP1252), а не фактическому системному ACP; другие code pages и точное совпадение Windows best-fit не заявлены. VALUE/time/date поддерживают существующий numeric ISO/ru/en срез, без month names и fractional seconds. Theme/tint colours, patterned/gradient fills, отдельные border sides/weights пока не выражены моделью; indexed system colours64/65 оставлены на default. Namespace aliases распознаются для relationship URI; исторические literal r: attributes сохранены для текущих fixtures. Fraction patterns поддерживают до999 variable denominator и до1000000 fixed denominator, без полного alignment/quoted-prefix corpus. Charts округляются до целого пикселя, общий импорт placement остаётся отдельным ограничением. Огромные merged areas с hidden anchor могут оставить прежнюю visible selection вместо выбора скрытого anchor. CPU/allocations и полный Office corpus требуют последующей разрешённой приёмки.

Финальные production изменения и access.rs прочитаны повторно: оставшихся блокеров по указанным путям не найдено. Resources в stateless пока не несут client_access; tools workflow отделён от этой незавершённой возможности. Это только чтение кода.
