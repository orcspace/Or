Новая возможность **вне10**: inspector получил категории, поиск по месту/описанию и копирование bounded отчёта. Копия включает область проверок, версию, устаревание и число не включённых замечаний. Фильтр применяется только к сохранённым первым200, overflow не маскируется.

`inspect_document` предоставляет тот же read-only срез AI. Первый вызов возвращает preparing; polling — completed, refresh запрашивает новый снимок. Явный document_id, snapshot/current versions, stale, stable targets, query/kind, index/count до100. В один момент одна проверка; другой документ получает busy. Не меняет active/selection/undo/dirty, не flush незавершённый ввод и не входит в workspace_apply. Кэш хранится в памяти. Вся проверка остаётся эвристической и частичной.

Добавлены регрессии важных путей; **ни одна Rust-регрессия не запускалась**. Статические ревью двух агентов выявили и закрыли собственную промежуточную ошибку cleanup чужого temp при create_new collision и неверный enum fixture "Rect" вместо "rect". Эти находки не входят в10. Fixture collision теперь отдельно сохраняет чужой файл. Экспортные reserved names writer дополнены по замечанию ревьюера в той же S5-02.

Первичные источники сверены16.10.2026: [Microsoft — имена в формулах](https://support.microsoft.com/en-us/excel/names-in-formulas), [Rust — copy](https://doc.rust-lang.org/std/fs/fn.copy.html), [Rust — rename](https://doc.rust-lang.org/std/fs/fn.rename.html), [MCP2026-07-28 tools](https://modelcontextprotocol.io/specification/2026-07-28/server/tools). Точная API-семантика закреплённых rust_xlsxwriter0.99.1/check_name, rmcp3.5.0, egui0.36.2 прочитана локально. Онлайн Rust docs сейчас показывают1.99.1, toolchain проекта не менялся.

Ограничения: полный parity и opaque OOXML round-trip не достигнуты; сложные Unicode identifiers, Excel locale/system ACP, файловые гонки внешних процессов, сетевые FS и power-loss durability требуют отдельной приёмки.1MiB JSON не означает возможность передать изображение1MiB байтов через JSON-array. Backup не обещает сохранение всех NTFS alternate streams/ACL — основное содержимое файла. Compile/runtime/визуальная проверка запрещены владельцем до отдельной команды.

Финальное независимое чтение обоих агентов завершено: MCP/API/UI, регрессии и util исправления перечитаны. Подтверждённых блокеров по исходнику не осталось. Annotation inspect_document idempotent=false учитывает refresh. Общие fmt-check, diff-check, spec registry (442 REQ/361 PAR) и assets check прошли; Rust-код не компилировался и не исполнялся.
