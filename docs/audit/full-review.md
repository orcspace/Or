# Полное ревью текущей версии — 2026-10-13

Основа: GitHub `claude/office-ui-mcp-fix`, `9639423`, последняя версия на момент начала проверки. Изменения подготовлены в `codex/full-review-minimal-ui`.

## Исправления

- Docs: сохранение видимого текста и наследуемых стилей HTML, корректные заголовки/Enter/поиск, DOTX/DOCM и переносы Markdown. Подробности: [Docs](full-review-docs.md).
- Sheets: изображения следуют структурным правкам; изменения формата, диапазона и массовая замена проверяются до мутации; нормализованные формулы не выходят за лимиты; исправлены TSV, порядок поиска и видимые/активные листы. Подробности: [Sheets](full-review-sheets.md).
- Slides: операции таблиц атомарны и ограничены безопасным размером, дублирование сохраняет группы/слои/буфер; текстовый экспорт сохраняет таблицы/диаграммы; показ корректно обрабатывает одновременно таймер и щелчок. Убрано клонирование байтов изображений в обработке холста. Подробности: [Slides](full-review-slides.md).
- Оболочка: длинные имена/пути обрезаются внутри строки недавних файлов; действия остаются доступны. Поиск и фильтры переносятся при нехватке ширины, лишние эмодзи заменены общей кодовой иконкой открытия.
- Палитра команд фильтрует все команды, включая открытие и настройки; доступны сохранение, копия, PDF и закрытие активного документа; Enter запускает первый результат. Пустой поиск показывает понятный статус.
- Настройка «Уменьшить движение» действительно отключает микроанимации оболочки без перезапуска.
- PDF с повёрнутыми объектами Slides требует подтверждения известной потери. Предупреждение экспорта не обещает полный без потерь Office roundtrip и читается в светлой теме.
- Отключённый MCP отклоняет неизвестных клиентов без лишнего окна разрешений.

## Дополнительный глубокий проход

- [Хранение/undo/recovery](full-review-storage.md): новый снимок восстановления записывается до удаления старого; очередь сохраняет передачу при новых записях/очистке; загрузчик не принимает временные и дублирующие файлы. Save As проверяет состояние цели до и после экспорта. Группа undo закрывается при отправке сохранения, а последующие правки не поглощают сохранённый текст. AI rollback оставляет видимый активный лист.
- [Форматы и рендер](full-review-formats.md): единая нормализация расширений, PPTM, согласованные безопасные ZIP-пути и фактические размеры, нормализация табуляции/мягких переносов в PDF, покрытие выбранного шрифта PNG, порядок текстовой/графической вставки, сохранность чужого временного файла при ошибке atomic write.
- [MCP](full-review-mcp.md): линейная массовая замена с проверкой объёма до выделения памяти; единый лимит ответов; строгие boolean и поля patch с учётом пропущенных сериализацией допустимых полей; защищённые диапазоны и скрытые листы; абсолютный путь шима и таймаут инициализации. Обработка очереди прекращает брать новые запросы после бюджета кадра (4 мс); время одной операции отдельно не сертифицировано.
- AI-чат: очередь событий ограничена, чат обрабатывает ответы и после скрытия панели; промежуточный текст сохраняется при завершении, ошибке, разрыве канала и Stop. Ожидание/завершение процесса больше не удерживает handle вне доступа Stop и не запускает taskkill в UI-потоке. stderr читается до конца с ограниченным хвостом, строки stdout ограничены 8 МБ и вывод запроса 32 МБ. Ненулевой exit больше не скрывается после частичного ответа.
- Завершение AI-процессов: Stop/Clear сохраняют владельца отменённого запуска и его поток очистки. При выходе приложение завершает активный CLI и ждёт уже запущенную очистку, включая отмену из обработчика лимитов. Обычный UI не ждёт taskkill; закрытие приложения больше не может обогнать detached cleanup.

Дополнительное перекрёстное ревью выявило и закрыло потерю cleanup Restore→Clear, отбрасывание допустимых MCP-полей `skip_serializing_if` и потерю уже поставленного в очередь текста при Stop. Граница undo при отправке сохранения добавлена в оболочке после рекомендации storage-ревью.

## Независимое ревью

## Проверки

До последнего исправления завершения AI-процессов прошли `cargo test --locked --workspace`: 265 тестов приложения + 14 shell-core, без ошибок. `cargo clippy --locked --workspace --all-targets -- -D warnings` также прошёл. Проверка реестра требований (442 REQ / 350 PAR), четыре Python-теста и проверка assets прошли. Последнее исправление и две новые проверки жизненного цикла проверены чтением кода и независимым ревью; повторные Rust tests/clippy не запускаются, поскольку требуют компиляции. Итоговое форматирование и `git diff --check` прошли.

По последнему указанию владельца «не надо build только фикси баги и улучшай ui интерфейс» сборка binaries остановлена; повторная сборка и выпуск установщика не выполняются. File/MCP/UI smoke на собранном приложении не выполнялся. Геометрия Home, фокус палитры и уменьшение движения проверены автоматическими egui-тестами; это не заменяет визуальную приёмку приложения.

## Ограничения

Это ревью существующего preview, не доказательство отсутствия любых багов и не реализация полного паритета Office. Продвинутые DOCX/PPTX roundtrip, XLSX conditional formatting, сложный HTML/Markdown, повороты PDF/PNG, второй экран докладчика, полная доступность/IME и производительность на большом корпусе остаются в объёме проекта. Установщик/релиз в этой фазе не выпускается.
