- До: Переносы/табуляция pretty HTML и пробелы между inline-узлами импортируются буквально.

## Проверка и пределы

- Изменения подготовлены в памяти и опубликованы через GitHub; исходники локально не восстанавливались. План фазы опубликован до изменений. Компиляция, runtime/UI, Office interop и производительность не подтверждены.
- HTML остаётся ограниченным importer, основанным на XML с нормализацией и прежним plain-text fallback; это не browser DOM/CSS и не полный HTML5 parser. Normal whitespace и pre/pre-wrap покрыты; pre-line, все CSS keywords/relative units и полная типографика остаются неполными.
- Font-size: добавлены проценты/em относительно computed родителя; line-height проценты/em сохраняются как computed absolute lengths. Не заявлен полный CSS cascade/stylesheet support.
- Таблицы HTML: до1000 таблиц,10000 строк/256 grid columns на таблицу и100000 совокупных ячеек, включая continuations. Поддержаны прямые tr/thead/tbody/tfoot, cell rich paragraphs, rowspan/colspan (включая rowspan=0 до конца текущей row group), colgroup widths, row/cell heights и доступные fill/vertical-align/border/padding. Разные per-cell borders/margins не представимы в текущей модели; берётся доступная общая геометрия. Row/stylesheet inheritance и все HTML table algorithms не реализованы. Вложенные таблицы и рисунки внутри ячеек явно отмечены как неподдержанные; содержимое таких объектов не обещается сохранить.
- Многоабзацные li представлены marker на первом абзаце и continuation indent на следующих; устойчивой модели list-item identity/start/reversed/value пока нет.
- Изображения HTML: PNG/JPEG data URI, стандартные числовые pixel attributes и абсолютные CSS width/height; без сети/relative file IO, процентного container sizing, object-fit/crop.
- DOCX hidden: учитываются docDefaults, toggle style inheritance и direct override, скрытые runs исключаются с loss notice. Переключение показа скрытого текста и lossless round-trip скрытых runs не реализованы. Double-strike упрощается до single-strike с notice. Пересмотренная block-level история импортируется в текущем виде, не как track-changes history.
- Markdown: исправлены конкретные edge cases существующего subset, полного CommonMark/GFM parity нет. Native raw LF экспортируется как hard break, при импорте нормализуется в VT внутри абзаца.
- replace_range выполняет preflight100000 абзацев,16 МиБ текста и счётчика ID до изменений и не копирует исходные runs для каждой строки. Совокупная модель/ops validate остаётся обязательной; это не доказательство целевых latency/memory budgets. Ошибки preflight передаются из checked cell path в set_cell_text/UI; прежний void edit_cell_text сохранён для совместимости.
- Старый тест смешанного HTML с таблицей обновлён на структурный импорт, с tab между ячейками. BUG-134 регрессия с native table остаётся и теперь обеспечена реальным parser, её assertions не ослаблены.
