## Уточнения и пределы

Остаточная schema omission BUG-230 исправлена в существующей регрессии, отдельного нового ID нет. Публичные changed_ids ограничены256; worker-only workspace path сохраняет полные IDs для точных totals, не открывает внешний обход. Pages не закреплены между версиями; большая одна ячейка/таблица или chart payload Slides по-прежнему может потребовать более узкого контракта. characters — Unicode scalars; Docs paragraph_id и Slides slide_id применяются до index/count. Размер возвращаемого окна ограничен, полностью потоковая сериализация исходной модели не реализована. Dry-run проверяет commit engine на минимальной копии, не выполняет side effects и не является performance acceptance.
