## Уточнения и пределы

Остаточная schema omission BUG-230 исправлена в существующей регрессии, отдельного нового ID нет. Public changed_ids ограничены256; worker-only workspace path (mcp/workspace.rs → prepare_operation) сохраняет полные IDs для точных totals и не открывает внешний обход. Pages не закреплены между версиями; большая одна ячейка/таблица или chart payload Slides по-прежнему может потребовать более узкого контракта. characters — Unicode scalars; Docs paragraph_id и Slides slide_id применяются до index/count. Размер возвращаемого окна ограничен, полностью потоковая сериализация исходной модели не реализована. Dry-run проверяет commit engine на минимальной копии, не выполняет side effects и не является performance acceptance.

Чат явно сообщает об удалении старых сообщений из локально видимой истории; CLI session/history files не изменяются. Переключение провайдера начинает новую сессию с общим bounded transcript, не обещает полный перенос всей истории. Ошибки oversize settings/input возвращаются до потребления draft/записи settings. EXIF применяется к декодированным pixels; это не обещание сохранения всех metadata при повторном экспорте. Поворот/отражение проверяются synthetic JPEG fixture в написанном, не запущенном тесте.

## Первичные источники

- [OpenType head/macStyle](https://learn.microsoft.com/en-us/typography/opentype/spec/head) и [Style Bits fallback](https://learn.microsoft.com/en-us/typography/opentype/otspec170/recom): OS/2 имеет приоритет, head даёт style при его отсутствии. Гипотеза об обязательном mapping OS/2 OBLIQUE в italic не включена.
- [image 0.25.10 Orientation](https://docs.rs/image/latest/image/metadata/enum.Orientation.html), [ImageDecoder](https://docs.rs/image/latest/image/trait.ImageDecoder.html) и [DynamicImage::apply_orientation](https://docs.rs/image/latest/image/enum.DynamicImage.html#method.apply_orientation): metadata orientation применяется вызывающим кодом.
- [ISO 32000-1 §8.4.3.2](https://developer.adobe.com/document-services/docs/assets/35e4369068f86065372c18787171a17e/PDF_ISO_32000-1.pdf): PDF zero line width означает минимально видимую линию на устройстве.
