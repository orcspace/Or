# Пакет 04 — многодокументные задания ИИ

Основа `0fb6408` / PR #6. Ветка `codex/review-50-ui-04`, PR поверх пакета03. Работа остановлена по ограничению владельца «ещё5 минут и финиш».

Изменения: [20 Sheets](review-50-04-core.md), [20 Docs/Slides](review-50-04-editors.md), [10 оболочка/MCP/AI](review-50-04-shell.md). Новая функция параллельной подготовки правок разных открытых документов не включена в число причин.

AI получает открытые документы, отправляет пакет с явными document_id/base_version и опрашивает job_id. Подготовка идёт в фоновых потоках; общий commit через ops проверяет все документы. Доступны preview, отмена, индикатор и отдельные авторские undo-группы. Активная вкладка сохраняется. Лимиты и неподдержанные случаи: [текущий MCP срез](../mcp-native-slice.md).

Новая белая минималистичная иконка уже опубликована в PR #6; этот пакет не меняет её повторно.

Сборка, cargo check/test/clippy, GUI, установщик, компилирующий CI и релиз не выполнялись. Компиляция, поведение в окне и производительность не подтверждены. Полный Office/MCP parity остаётся незавершённым.

Поэтому PR опубликован как draft, второе итоговое ревью остаётся обязательным незавершённым шагом. Промежуточные CRLF/Arc baseline/schema риски новой реализации исправлены и в квоту не добавлены.
