# Минималистичный интерфейс — фаза06

Запрос владельца: полностью улучшить UI, сделать более минималистичным. Основа: PR8,5078a6d. Этот пакет посвящён интерфейсу; новые фичи и визуальные правки не выдаются за50 исправленных багов. Сборки/cargo check/test/clippy, запуск приложения/GUI, установщик/релиз и merge не выполнять до отдельной команды. Стек и зависимости прежние.

Направление: светлая нейтральная оболочка, мягкий серый workspace, белый документ, тонкие разделители,4px ритм/6–10px радиусы, минимум постоянных рамок/заливок. Контраст и состояния фокуса сохраняются. Акценты только по редактору: синий/зелёный/оранжевый. Тёмная/системная темы сохраняются. Постоянные команды сокращаются до основных; расширенные параметры в раскрываемых группах/меню, команды не удаляются. На узкой ширине доступны прокрутка/адаптивное упрощение, а не обрезанные кнопки.

Области: root — общие chrome tokens/primitives, Главная/открытые вкладки/меню/status/AI shell, общая документация. Агент1 — Docs/Slides ribbons/canvas/sidebar только editor.rs, без model/ops/io изменений. Агент2 — Sheets ribbon/formula/sheet tabs и Chat визуальная иерархия только sheets/editor.rs+chat.rs, без изменения запуска/прав/модели. Оба после реализации независимо перечитывают чужой и root diff.

Сначала согласовать небольшие shared chrome API, затем привести все три редактора и оболочку к одной системе. Сохранить корректную доставку редактирования/фокус, stateIDs, сочетания клавиш, все реальные команды, честные disabled/unavailable подписи, видимые stop/save/read-only/error состояния. Изменения UX не должны обходить общий ops.

Исследование: актуальные первичные Fluent2 layout/typography и Windows CommandBar guidelines, локальные egui0.36.2 API. Источники и ограничения — в итоговом audit. Без новых растровых ассетов/шрифтов/библиотек. Проверка: статический review двух агентов, cargo fmt --all -- --check, git diff --check, spec registry, assets. Никаких тестов, зеркалящих стили; регрессии трогать только при настоящей функциональной необходимости и не запускать. Runtime/визуальная приёмка остаётся непроверенной из-за запрета на запуск/сборку.

Результат: отдельный PR поверх codex/review-50-ui-05 с [skip ci], перечислением конкретных поверхностей и непроверенного. При расширении функциональности обновить parity.json и сгенерированную parity.md; чистую рестилизацию не считать Office parity приёмкой.

Результат фазы: шесть UI source-файлов, shortcuts и три audit отчёта. Два независимых статических review завершены, замечания закрыты. fmt/diff/registry/assets проверки прошли; приёмка запущенного интерфейса не выполнялась. Сводка и точные ограничения — docs/audit/minimal-ui-06.md. Стек/модель/форматы/права не менялись. Публикуется отдельным UI PR поверх PR8 с [skip ci], без merge.
