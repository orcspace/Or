# План после 0.0.4: что добавить, исправить и улучшить

Дата: 2026-10-13. Составлен после выпуска 0.0.4. Пункты отобраны по коду и известным ограничениям, а не по отзывам пользователей. Приоритет: **P1** — заметно мешает работе с чужими файлами Office, **P2** — важная функция, **P3** — полировка.

## Документы (DOCX)

| Приоритет | Что | Сейчас |
|---|---|---|
| P1 | Сноски и концевые сноски (`footnotes.xml`, `endnotes.xml`) | При импорте выдаётся предупреждение «Сноски не импортированы», текст сносок теряется |
| P1 | Колонтитулы первой и чётных страниц (`titlePg`, `evenAndOddHeaders`) | Используется только колонтитул по умолчанию |
| P1 | Поля в тексте документа: `TOC`, `NUMPAGES`, перекрёстные ссылки | `PAGE` в колонтитуле распознаётся как номер страницы; поля в основном тексте показывают сохранённый результат и не обновляются |
| P2 | Обтекание картинок (`wrapSquare`, `wrapTight`, `anchor`) | Плавающие рисунки переводятся в отдельные блоки между абзацами |
| P2 | Многоуровневые списки: `lvlOverride` и перезапуск нумерации | `numbering.xml` читается, `lvlOverride` не обрабатывается |
| P2 | Проверка орфографии (русский и английский) | Нет |
| P3 | Разделы с разными параметрами страницы (ориентация, поля) | Проверить и довести до соответствия Word |

## Таблицы (XLSX)

| Приоритет | Что | Сейчас |
|---|---|---|
| P1 | Условное форматирование (`conditionalFormatting`) | Не читается и теряется при сохранении |
| P1 | Проверка данных и выпадающие списки (`dataValidation`) | Не читается и теряется при сохранении |
| P2 | Импорт диаграмм из XLSX | Диаграммы, созданные в TrineDocs, работают; чужие диаграммы из файла не импортируются |
| P2 | Динамические массивы: `FILTER`, `SORT`, `UNIQUE`, разлив результата по ячейкам | Нет (`XLOOKUP` уже есть) |
| P2 | Кнопки фильтра в заголовках столбцов (`autoFilter`) | Проверить текущую поддержку и сделать фильтр как в Excel |
| P3 | Именованные диапазоны (`definedName`) в формулах | Не читаются |

## Презентации (PPTX)

| Приоритет | Что | Сейчас |
|---|---|---|
| P1 | Произвольные фигуры (`custGeom`) | Приближаются прямоугольником, при импорте выдаётся предупреждение |
| P1 | Импорт диаграмм и SmartArt | Диаграммы из TrineDocs экспортируются; чужие диаграммы и SmartArt не импортируются |
| P2 | Точная отрисовка градиентной и узорной заливки | Сплошная заливка поддержана; градиенты и узоры упрощаются |
| P2 | Видео и аудио на слайде | Не поддерживаются |
| P2 | Режим докладчика на втором мониторе (заметки, таймер, следующий слайд) | Нет |
| P3 | Переход «Трансформация» (morph) и пути перемещения | Нет |
