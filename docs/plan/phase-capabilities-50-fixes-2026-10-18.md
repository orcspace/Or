## Возможности и критерии

1. Паспорт формулы Sheets: исходная формула, тип/значение, прямые и именованные зависимости, адреса/размеры диапазонов, ошибки ссылок. Доступен из UI и read-only MCP, ограничен по объёму, не пересчитывает и не изменяет книгу.
2. Специальная вставка Sheets: всё / значения / формулы и ввод / только форматы, транспонирование. Числа/логические значения/ошибки/текст сохраняют тип; формулы смещаются для Copy; ошибки диапазона/merge атомарны. Обычная вставка и TSV совместимы с PR #10.
3. Линза оформления Docs: read-only сравнение фактических run-форматов с базой именованного стиля, отдельная категория инспектора, переход к стабильному paragraph ID, bounded UI/MCP-отчёт.
4. Повестка Slides: список видимых слайдов с разделами/заголовками, предпросмотр перед добавлением, создание обычного редактируемого слайда через текущий путь undo. Скрытые слайды пропускаются, размер и переполнение контролируются.

Все четыре функции доводятся до доступного пользователю вертикального среза и регрессий, а не только до спецификации. Дополняется docs/parity.md с честным implemented_unverified.
