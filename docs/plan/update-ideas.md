# Идеи обновлений

Правило владельца от 2026-10-15: каждый следующий пакет ориентирован на 50 различных подтверждённых исправлений, две независимые проверки и улучшения UI в минималистичном направлении. Фичи и дубли не подменяют баги. В отчёте всегда указываются фактическое число и уровень проверки. По новому указанию владельца работа продолжается самостоятельно до команды «стоп». Периодическое расписание не настраивается; пакеты выполняются последовательно в текущей задаче.

В текущий код добавлены фильтр недавних/закреплённых по редактору и палитра команд с управлением стрелками. Runtime/visual QA отложены владельцем вместе со сборкой.

| Редактор | Следующая идея | Польза | Приоритет / parity |
|---|---|---|---|
| Docs | Проверка структуры | Находит пропуски уровней заголовков, пустые заголовки и картинки без описания; переход к stable ID | P1 / PAR-TRI-033 |
| Sheets | Паспорт формулы | Показывает цепочку зависимостей и объясняет полученный результат на конкретных входах | P1 / PAR-TRI-034 |
| Slides | Проверка читаемости | Выделяет переполнение текста, слабый контраст и мелкий шрифт | P1 / PAR-TRI-035 |
| Общее | Карточка плана AI | До правки показывает затронутые объекты и diff; проверяет base_version перед применением | P1 / PAR-TRI-036 |

На момент первого пакета все четыре идеи были planned; прогресс второго указан ниже. Новые инструменты MCP и зависимости не добавлены; изменять стек не требуется. Форматы и полный Office parity сохраняют прежний объём.

## Пакет 02

В код добавлена фоновая команда «Проверить документ»: структура Docs, ошибки Sheets, границы объектов и читаемость обычного текста Slides. Автоисправления не выполняются. Поддержка Docs/Slides в parity partial_unverified; runtime/GUI ещё не проверялись.

Следующие идеи: карта отличий прямого форматирования от стилей Docs (PAR-TRI-038); паспорт формулы Sheets (PAR-TRI-034); повестка Slides из разделов/заголовков с предпросмотром (PAR-TRI-039); карточка плана AI перед commit (PAR-TRI-036). Все четыре остаются planned и не выдаются за готовые функции.

## Пакет 03

Инспектор получил переход по stable ID: абзац/якорь картинки Docs, видимая ячейка Sheets, объект Slides. Устаревшие и скрытые цели не активируются. Поддержка остаётся unverified до runtime/GUI проверки.

Новые идеи следующего пакета: поиск и фильтр замечаний по типу; копирование отчёта проверки в буфер; предупреждение перед массовой заменой формул с кратким предпросмотром. Сначала — подтверждённые дефекты и сохранность данных; идеи не считаются исправленными багами.

По новому запросу владельца приоритет следующего пакета — инструменты ИИ для нескольких открытых Docs/Sheets/Slides: явные document_id/base_version, фоновые независимые задания, общий пакет правок с понятным результатом и отменой. Новая белая иконка уже включена в пакет03. Факты каждого обновления сверяются по актуальным первичным интернет-источникам; сборка остаётся только по отдельной будущей команде.
