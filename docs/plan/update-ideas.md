# Идеи обновлений

Правило владельца от 2026-10-15: каждый следующий пакет ориентирован на 50 различных подтверждённых исправлений, две независимые проверки и улучшения UI в минималистичном направлении. Фичи и дубли не подменяют баги. В отчёте всегда указываются фактическое число и уровень проверки. Работа выполняется по следующему запросу; фоновая автоматическая периодичность не настроена.

В текущий код добавлены фильтр недавних/закреплённых по редактору и палитра команд с управлением стрелками. Runtime/visual QA отложены владельцем вместе со сборкой.

| Редактор | Следующая идея | Польза | Приоритет / parity |
|---|---|---|---|
| Docs | Проверка структуры | Находит пропуски уровней заголовков, пустые заголовки и картинки без описания; переход к stable ID | P1 / PAR-TRI-033 |
| Sheets | Паспорт формулы | Показывает цепочку зависимостей и объясняет полученный результат на конкретных входах | P1 / PAR-TRI-034 |
| Slides | Проверка читаемости | Выделяет переполнение текста, слабый контраст и мелкий шрифт | P1 / PAR-TRI-035 |
| Общее | Карточка плана AI | До правки показывает затронутые объекты и diff; проверяет base_version перед применением | P1 / PAR-TRI-036 |

Все четыре идеи пока planned. Новые инструменты MCP и зависимости не добавлены; изменять стек не требуется. Форматы и полный Office parity сохраняют прежний объём.
