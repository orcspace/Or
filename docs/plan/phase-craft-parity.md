# Срез: функции из WordCraft, GridCraft и DeckCraft

Дата: 2026-10-17. Решение: ADR-0028. Источники читаются через GitHub API, без клонирования на машину владельца; сборка и тесты — только в CI.

## Волна 1 — функции листа (выполнено, CI зелёный)
1. Вендорная библиотека `crates/trinedocs/src/sheets/xlfn/` (≈490 функций GridCraft) с тестами upstream.
2. Мост: неизвестное движку имя → `xlfn::lookup`/`xlfn::call`; диапазоны → массивы с признаком ссылки; ошибки и массивы возвращаются как значения движка.
3. `regex =1.13.1` для REGEX*-функций; Cargo.lock дополнен четырьмя crates.
4. Тест `library_functions_fill_the_gaps`: статистика, финансы, матрицы, ERROR.TYPE, SEQUENCE, REGEX*, TEXTSPLIT, DSUM/DCOUNT, ошибки арности/типа.
5. Паритет: PAR-SHT-122…126 (`partial_unverified`).
6. После загрузки crates — `python -B tools/audit_dependencies.py --refresh` и коммит `docs/licenses.md`/`docs/audit/dependencies.md`.

## Волна 2 — массивы листа
- Разлив результатов-массивов на соседние ячейки, `#SPILL!`, ссылка `A1#`.
- LET, LAMBDA, MAP/REDUCE/SCAN/BYROW/BYCOL, OFFSET/INDIRECT.

## Волна 3 — интерфейс листа
- Подсказки функций в строке формул: список по префиксу, сигнатура и описание из `xlfn` и встроенных функций (выполнено, PAR-SHT-021).
- Окно «Вставить функцию» по категориям.

## Волна 4 — документы и слайды
- OpenDocument Text (`.odt`/`.ott`/`.fodt`): собственные читатель и писатель `docs/io/odt.rs` по образцу `formats::odt` WordCraft, на нашей модели — без вендоринга чужой модели документа (выполнено, PAR-DOC-097 `partial_unverified`).
- RTF: импорт и экспорт.
- Русская проверка орфографии WordCraft требует системного словаря Hunspell, которого на Windows нет; не переносится.
- Сверка возможностей WordCraft и DeckCraft с нашими редакторами по исходникам; перенос недостающих функций по смыслу в нашу модель (`docs`, `slides`), каждая с тестом и записью паритета.

## Волна 5 — оформление
- Общая полировка интерфейса по итогам волн 3–4: отступы, иконки, состояния, тёмная тема.

## Проверка
Каждая волна: `cargo fmt`, clippy `-D warnings`, `cargo test --locked`, `spec_registry.py check` в CI. Ни одна функция не объявляется готовой без теста.
