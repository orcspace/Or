# Пакет 03: точность редактирования и навигация проверки

Разрешение владельца от 2026-10-15: продолжать самостоятельно до «стоп», публиковать изменения в GitHub без сборок. Основа — `1782345`, PR #5. Отдельный PR поверх `codex/review-50-ui-02`; предыдущие PR автоматически не сливать.

1. Два независимых агента проверяют Sheets (формулы, ссылки, пересчёт, редактор) и Docs/Slides (сохранность содержимого, ввод, layout, импорт/экспорт). Ведущий проверяет оболочку, файловые операции, recovery, ops, MCP и интеграцию. Ориентир — 50 различных подтверждённых причин; предыдущие исправления и отсутствующий parity не пересчитывать как новые баги.
2. До правок фиксировать конкретный production-сценарий и причину. Сохранять операции и stable ID, текущий стек и лицензии. Все мутации — с orell_flow, атомарным claim и перечитыванием после grant. Новые зависимости не нужны.
3. Улучшить компактный UI фоновой проверки документа: переход от замечания к его объекту, сохранение контекста и честная обработка устаревшего результата. Новые полезные идеи оценить отдельно; фичи не входят в число багов.
4. Провести взаимное независимое чтение конечных изменений. Допустимы статические rustfmt/check-format, diff-check, read-only проверки спецификации и assets. Rust-регрессии добавлять по необходимости, не запускать. Не запускать сборку, cargo test/check/clippy, GUI, установщик, компилирующий CI или релиз.
5. Опубликовать отдельные отчёты, реестр сценариев, ограничения и результаты проверок в GitHub PR. Коммит с `[skip ci]`. Указать фактический объём; после публикации продолжить работу до команды владельца.

Дополнение владельца в ходе пакета: обновить иконку на белом фоне (включено в этот пакет); усилить инструменты ИИ для параллельной работы с несколькими редакторами (следующий отдельный пакет, с актуальными первичными интернет-источниками). Сборка разрешается только отдельной будущей командой владельца.
