# Отчёт: исправления полного ревью — 2026-10-18

## Реализовано

- Включены два существующих исправляющих коммита ae5aa5e и 8593792 поверх main 853f3a4: проверки MCP base_version, VALUE/XLOOKUP, точные размеры XLSX и рисунков, кнопка нового листа. Более поздние функции preview-ветки не включены.
- Для Codex явно отключены shell, просмотр локальных изображений, REPL, дополнительные агенты, приложения, плагины и hooks. Перед запуском читается эффективный список MCP того же CLI/каталога; каждый посторонний сервер отключается отдельной записью в таблице override. Пустая таблица не используется как способ очистки, поскольку Codex глубоко объединяет TOML. Ошибка обнаружения запрещает запуск. Вывод ограничен 4 МиБ; обнаружение отменяется существующим Stop. Настройки и авторизация пользователя не меняются.
- Для каждой независимой формулы сбрасываются счётчики работы и материализации. Корректный кэш зависимостей сохраняется; результаты, полученные после исчерпания лимита, не кэшируются.
- PDF/печать Slides исключают скрытые слайды, сохраняя порядок остальных. HTML Sheets исключает скрытые листы, строки и столбцы.
- Внутренний буфер Sheets хранит исходный ввод и формат ячейки. Copy переносит относительные ссылки, Cut сохраняет ссылки исходной формулы. Вставка создаёт собственные ID и проверяет кандидат книги до замены; внешний текст остаётся TSV. Снимок внутреннего буфера используется только при совпадении текста системного буфера.
- DOCX AlternateContent нормализуется до разбора абзацев, runs и изображений. Выбирается первая Choice, все Requires которой разрешаются в поддерживаемые URI пространств имён; иначе Fallback. Остальные альтернативы исключаются, включая вложенные внутри run.
- Ключ текстуры изображения Sheets включает байты, поэтому одинаковые ID и длина разных изображений не переиспользуют старую текстуру.
- Добавлены 12 целевых Rust-регрессий для этих сценариев. Существующий тест AlternateContent приведён к корректной Choice с Requires, с сохранением ожидаемого изображения.

## Проверка и ограничения

Работа выполнена одним агентом через GitHub. Изменения и вызовы потребителей просмотрены статически. Не выполнялись сборка, cargo check/test/clippy/fmt, запуск приложения, установщик или GitHub Actions. Новые коммиты и заголовок PR содержат [skip ci].

Новые тесты не запускались. Успешный CI старой preview-ветки не является проверкой этого исправления. Совместимость параметров с установленной версией Codex CLI и фактическая поверхность инструментов требуют будущей разрешённой runtime-проверки. Внутренний буфер доступен в текущем процессе приложения; межпроцессный обмен использует текстовый TSV.
