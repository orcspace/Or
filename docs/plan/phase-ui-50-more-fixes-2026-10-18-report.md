## Результат

Внесены исправления 50 отдельных дефектов BUG-051…BUG-100. [Реестр](../audit/bugs-51-100-2026-10-18.md) содержит причину, пример до/после, файл и имя целевой регрессии для каждого. Добавлены 50 тестовых функций: chrome 3, settings 1, Sheets format 5 / calculation 4 / model 2 / editor 3 / IO 4, Docs IO 25, Slides presenter 2 / IO 1. Наличие тестов проверено по исходникам; они не запускались.

- Общий UI: вкладки ленты прокручиваются в узком окне; палитры имеют имена цветов, tooltip, видимый фокус и выбор; поиск шрифта изолирован по родительскому UI; отсутствие цвета видно по перечёркнутой полоске.
- Sheets: панель поиска с переносом команд, режимом регистра, кнопками назад/вперёд, Enter/Shift+Enter/Esc, счётчиком и пояснением области замены. Поиск хранит позиции, не копии текста всех найденных ячеек. Статистика выделения вынесена из списка листов, использует локаль и масштабированное среднее.
- Slides: рисунок пером сохраняет позицию относительно слайда при изменении размера; перо/указка ограничены слайдом. Клавиша Space в кнопке докладчика выполняет её действие без одновременного перелистывания.
- Импорт: HTML CSS/цвета/списки/сущности/изображения; Word theme/style/shading/table/part relationships; Excel базовые xf/font scheme/выделение/chart title; PowerPoint отделяет endParaRPr будущего ввода от существующего текста.
- Ресурсы: общий текстовый бюджет replace-all, bounded text calculation cache и отсутствие записей для несуществующих пустых ячеек.

Косметика и новая навигация не добавлены к счёту дефектов. Esc, отличие регистра, потеря данных и ошибочные числа имеют отдельные воспроизводимые причины.

## Проверка и ограничения

Выполнено только чтение исходников, сопоставление до/после, проверка объявлений регрессий и статическая сверка опубликованного diff/ветки. Лексическая проверка скобок/строк в памяти не является Rust parser/typecheck. При чтении исправлены ошибочная граница raw-string, устаревший вызов тестового UI API и ссылка на отсутствующий helper.

По указанию владельца не запускались build, tests, fmt, lint, installer, приложение или GitHub Actions. Коммиты содержат [skip ci]. Компиляция, выполнение тестов, реальный вид при 780/1250 px, DPI/масштабировании, клавиатурная навигация и экранный диктор не подтверждены. Draft не означает готовность к merge/release.

Остаются ограничения модели Office, перечисленные в реестре. В частности: HTML не является полным браузерным парсером/CSS cascade; inline images якорятся после абзаца; Word shading patterns и сложные скрипты не воспроизводятся полностью; XLSX multi-selection и activeCell внутри диапазона не представимы целиком; графики с произвольными межлистовыми рядами не исправлялись. Unicode literal search не является locale-aware collation/regex.

Новых зависимостей, изменений версий Rust/egui, unsafe и production unwrap/expect не добавлено. MCP-схемы не менялись; новые элементы используют прежний UI→ops/undo путь. Паритет обновлён как unverified, полный Office parity не заявляется.

## Приёмка после разрешения запусков

1. Сначала compile/typecheck и 50 целевых регрессий, затем существующие проверки затронутых редакторов.
2. Ручная проверка ленты/палитр/поиска при узком окне, разных DPI и масштабе, Tab/Enter/Esc, read-only и незавершённом вводе.
3. Просмотр внешних HTML/DOCX/XLSX/PPTX fixtures в Or и Office; проверка сохранения/undo и ограничений импорта.
4. Перо и фокус панели докладчика при resize/fullscreen и автоматических переходах.
