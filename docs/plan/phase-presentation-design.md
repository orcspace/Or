# Срез: навык дизайна презентаций и медиа-инструменты AI

Дата: 2026-10-16. Решение: ADR-0027.

## План
1. Навык `crates/trinedocs/src/mcp/skills/presentation_design.md`. Разделы:
   - сюжет;
   - сетка 960×540;
   - типографика;
   - 8 палитр;
   - пары системных шрифтов;
   - рецепты слайдов с координатами;
   - изображения и атрибуция;
   - анимации;
   - порядок инструментов;
   - чек-лист.
2. MCP-инструменты:
   - `slides_design_guide`;
   - `slides_search_images`;
   - `slides_add_image_url`;
   - `slides_generate_image`;
   - `slides_format_text`;
   - `slides_animate`;
   - `slides_align`;
   - рабочий `export`;
   - `x`/`y`/`as_background` у `slides_add_*`.
3. Фоновые задания `mcp-media` в `app.rs`. Ожидание на сервере 90 с для медиа-инструментов.
4. Чат:
   - правило «сначала slides_design_guide»;
   - список новых инструментов в промпте Slides;
   - подписи шагов.

## Отчёт
Сделано: пункты 1–4. Добавлены unit-тесты:
- `mcp::media` — генератор, цвета, URL, обрезка, имя файла;
- `mcp::tools` — навык без документа, пакетный формат, stagger, выравнивание и распределение, x/y.

**Не проверено:** по указанию владельца код в этом срезе не собирался и тесты не запускались. Перед приёмкой нужны:
- `cargo build`;
- `cargo test -p trinedocs`;
- `cargo clippy`;
- ручная проверка в чате: создать презентацию, найти и вставить фото, сгенерировать фон, экспортировать pptx/pdf.

Исправлено во втором проходе:
- Анимации входа пишутся в PPTX `p:timing` (Fade, Fly In справа, Zoom; click/with/after, delay, duration) и читаются обратно из внешних PPTX.
- У анимации есть поле `order`; шаги идут в порядке `element_ids` вызова `slides_animate`, а не по слоям.
- Загрузка резолвит имя, отклоняет непубличные адреса (включая CGNAT, NAT64, v4-mapped) и закрепляет проверенный IP через `curl --resolve`; редиректы обрабатываются вручную с проверкой каждого шага (до 4).
- MCP-экспорт PNG создаёт папку с картинкой каждого показываемого слайда.

Известные ограничения:
- Нет нейросетевой генерации изображений.
- Codex CLI без веб-поиска.
- Пункт меню «Файл → Экспорт → PNG» по-прежнему выдаёт только первый слайд.
- Поддерживаются только эффекты входа; выделение, выход и пути PowerPoint при импорте заменяются появлением или пропускаются с предупреждением.
- Сложные `after_previous`-цепочки внешних PPTX при импорте приближённые.
- Старый curl Windows 10 может не поддерживать IPv6 в квадратных скобках в `--resolve`; тогда загрузка с IPv6-only хоста завершится ошибкой.

Следующий шаг:
- сборка и тесты на Windows;
- открыть готовый PPTX в PowerPoint и проверить анимации;
- выбор папки экспорта с подтверждением пользователя.
