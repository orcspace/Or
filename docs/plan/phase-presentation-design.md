# Срез: навык дизайна презентаций и медиа-инструменты AI

Дата: 2026-10-16. Решение: ADR-0027.

## План
1. Навык `crates/trinedocs/src/mcp/skills/presentation_design.md`. Разделы:
   - сюжет;
   - сетка 960×540;
   - типографика;
   - 8 палитр;
   - пары системных шрифтов;
   - рецепты слайдов с координатами;
   - изображения и атрибуция;
   - анимации;
   - порядок инструментов;
   - чек-лист.
2. MCP-инструменты:
   - `slides_design_guide`;
   - `slides_search_images`;
   - `slides_add_image_url`;
   - `slides_generate_image`;
   - `slides_format_text`;
   - `slides_animate`;
   - `slides_align`;
   - рабочий `export`;
   - `x`/`y`/`as_background` у `slides_add_*`.
3. Фоновые задания `mcp-media` в `app.rs`. Ожидание на сервере 90 с для медиа-инструментов.
4. Чат:
   - правило «сначала slides_design_guide»;
   - список новых инструментов в промпте Slides;
   - подписи шагов.

## Отчёт
Сделано: пункты 1–4. Добавлены unit-тесты:
- `mcp::media` — генератор, цвета, URL, обрезка, имя файла;
- `mcp::tools` — навык без документа, пакетный формат, stagger, выравнивание и распределение, x/y.

**Не проверено:** по указанию владельца код в этом срезе не собирался и тесты не запускались. Перед приёмкой нужны:
- `cargo build`;
- `cargo test -p trinedocs`;
- `cargo clippy`;
- ручная проверка в чате: создать презентацию, найти и вставить фото, вставить скопированное фото, экспортировать pptx/pdf.

Исправлено во втором проходе:
- Анимации входа пишутся в PPTX `p:timing` (Fade, Fly In справа, Zoom; click/with/after, delay, duration) и читаются обратно из внешних PPTX.
- У анимации есть поле `order`; шаги идут в порядке `element_ids` вызова `slides_animate`, а не по слоям.
- Загрузка резолвит имя, отклоняет непубличные адреса (включая CGNAT, NAT64, v4-mapped) и закрепляет проверенный IP через `curl --connect-to`; редиректы обрабатываются вручную с проверкой каждого шага (до 3 переходов).
- MCP-экспорт PNG создаёт папку с картинкой каждого показываемого слайда.

Итоговый проход:
- Добавлен `slides_paste_image`: вставка скопированного изображения без чтения текста буфера.
- Несколько эффектов на объект, append/полная цепочка, вход/выделение/прямой путь/выход; PPTX writer/reader и порядок шагов обновлены.
- Экспорт PNG из меню сохраняет все показываемые слайды; дополнительные файлы не перезаписываются. Новый MCP-экспорт публикуется без перезаписи.
- Загрузка через `--connect-to`: поддержан IPv6 старого curl, отключены curlrc/прокси, ограничены chunked-ответы. Отменённые задания учитываются в лимите до завершения.
- Нейрогенерация исключена уточнением владельца; SVG-прототип удалён. У любого MCP-клиента остаются поиск и вставка интернет-картинок.
- Добавлены регрессии для цепочек показа, внешних PPTX-таймингов, бинарных загрузок, закрепления host/IP и сохранения без перезаписи.

Не приняты за готовые: полный каталог эффектов/кривых путей/объектных триггеров PowerPoint; поворот таблиц/диаграмм на холсте и повороты в PDF/PNG. Приближения отражаются в warnings/parity. Новые файлы экспорта требуют hard links (NTFS).

Следующий шаг:
- сборка и тесты на Windows;
- открыть готовый PPTX в PowerPoint и проверить анимации;
- выбор папки экспорта с подтверждением пользователя.

## Завершение по уточнению владельца
План: поиск и вставка интернет-картинок через MCP для любого AI-клиента; вставка из буфера; без нейрогенерации, API-ключей и отдельного раздела генерации. Завершить несколько шагов анимации на объект и PPTX-тайминги; исправить PNG всех слайдов и перезапись соседних файлов; проверить схемы, форматирование и документацию. Локальную сборку не запускать.

## Выполненные проверки завершения
`cargo fmt --all -- --check`, `git diff --check`, `python -B tools/spec_registry.py check` (442 REQ / 361 PAR), 4 Python regression-теста и check_assets проходят. Публичный Openverse API с фильтром jpg/png и лицензий ответил HTTP 200. Это не проверка исполнения Rust/GUI; локальная сборка не выполнялась.

Первый CI на GitHub обнаружил три старых несовместимых byte/string сравнения в Sheets XML и две недостижимые ветки описаний Slides. Исправлены в исходном коде, без изменения формата или зависимости. Rust-проверки повторяются только на GitHub.

Второй CI подтвердил компиляцию и выявил 10 Clippy-замечаний. Исправлены: Box для снимка файлового Job::Save, именованные типы timing-групп, эквивалентные упрощения UI и лишних заимствований. Проверки не отключались.
