# Срез: навык дизайна презентаций и медиа-инструменты AI

Дата: 2026-10-16. Решение: ADR-0027.

## План
1. Навык `crates/trinedocs/src/mcp/skills/presentation_design.md`. Разделы:
   - сюжет;
   - сетка 960×540;
   - типографика;
   - 8 палитр;
   - пары системных шрифтов;
   - рецепты слайдов с координатами;
   - изображения и атрибуция;
   - анимации;
   - порядок инструментов;
   - чек-лист.
2. MCP-инструменты:
   - `slides_design_guide`;
   - `slides_search_images`;
   - `slides_add_image_url`;
   - `slides_generate_image`;
   - `slides_format_text`;
   - `slides_animate`;
   - `slides_align`;
   - рабочий `export`;
   - `x`/`y`/`as_background` у `slides_add_*`.
3. Фоновые задания `mcp-media` в `app.rs`. Ожидание на сервере 90 с для медиа-инструментов.
4. Чат:
   - правило «сначала slides_design_guide»;
   - список новых инструментов в промпте Slides;
   - подписи шагов.

## Отчёт
Сделано: пункты 1–4. Добавлены unit-тесты:
- `mcp::media` — генератор, цвета, URL, обрезка, имя файла;
- `mcp::tools` — навык без документа, пакетный формат, stagger, выравнивание и распределение, x/y.

**Не проверено:** по указанию владельца код в этом срезе не собирался и тесты не запускались. Перед приёмкой нужны:
- `cargo build`;
- `cargo test -p trinedocs`;
- `cargo clippy`;
- ручная проверка в чате: создать презентацию, найти и вставить фото, сгенерировать фон, экспортировать pptx/pdf.

Известные ограничения:
- Анимации объектов не пишутся в PPTX timing.
- Порядок шагов по щелчку определяется слоями.
- Нет защиты от DNS-имён, которые разрешаются во внутренние адреса.
- Нет нейросетевой генерации изображений.
- Экспорт PNG выдаёт только первый слайд.
- Codex CLI без веб-поиска.

Следующий шаг:
- сборка и тесты на Windows;
- запись анимаций в `p:timing`;
- порядок анимаций, независимый от слоёв;
- выбор папки экспорта с подтверждением пользователя.
