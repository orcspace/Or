# ADR-0009: Название и расширения

Статус: **ждёт владельца**, предварительные проверки не выполнены.

Варианты: оставить TrineDocs / новое уникальное имя; `.trinedoc/.trinesheet/.trineslide` / единый versioned container extension. Критерии: сходные document-product names, domains, trademarks classes (кандидаты 9/42 — ещё проверить), existing extension collisions, OS association.

Рекомендация: внутреннее кодовое имя TrineDocs, не регистрировать домены/знак/ассоциации до проверки. Доступность и юридическая безопасность **не подтверждены**; передать владельцу/юристу. Branding rename cost оценивается после поиска, не на глаз.
