# ADR-0005: Объём v1 и порядок фаз

Статус: **ждёт владельца**.

SPEC-AUDIT предлагает Docs → Sheets → MCP/AI → collaboration → export/print; исходная схема Docs → export/print → MCP/AI → collaboration → Sheets. Нельзя одновременно исполнять обе. Slots всех требований сохраняются, Slides/следующие заблокированы до решения владельца.

| Вариант | Плюсы | Минусы/затраты |
|---|---|---|
| Исходная схема | ранние файлы/PDF/печать подтверждают реальную Word-вёрстку | Sheets приходит позже |
| Новый порядок без перестановок | ранние два редактора | проверка точности через PDF/print откладывается; зависит от native format |
| Тонкие docx/PDF рано, остальная печать после collaboration | ранний end-to-end файл и ранние Sheets | нужно разделить критерии/номера фаз; объём согласовывает владелец |

Рекомендация: третий вариант, но ни один не принят. Трудозатраты требуют результатов layout/CRDT/formula spikes; числовая оценка сейчас неизвестна. Фаза 0 независима, продолжается. Нумерацию требований не менять при перенумерации фаз.
