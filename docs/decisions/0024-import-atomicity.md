# ADR-0024: Ошибка импорта Loro не гарантирует отсутствие изменений

Статус: **предложено; защита в production ещё не реализована**. Дата: 2026-10-13.

## Контекст и доказательство

Требования REQ-03-016 и REQ-M06-072 требуют общего пути ops и атомарного apply_ops. Изолированный Loro 1.16.2 [compaction probe](../../spikes/crdt/src/lib.rs) воспроизводит ImportUpdatesThatDependsOnOutdatedVersion: пакет включает старую офлайн-правку и допустимую правку после shallow cutoff. Импорт возвращает ошибку, но применяет допустимую часть. Это не гарантия all-or-nothing.

Primary source: [официальная crate 1.16.2](https://crates.io/api/v1/crates/loro/1.16.2), source checksum закреплён. Upstream tests/integration_test/shallow_snapshot_test.rs содержит аналогичный контракт. Docs.rs оказался недоступен через браузерный поиск; вывод основан на exact downloaded source и собственном воспроизведении, а не на неподтверждённой документации.

## Варианты

| Вариант | Достоинства | Риски/стоимость |
|---|---|---|
| Проверить на staging replica/fork, затем публиковать при неизменной базе | ошибочный пакет не меняет live-state; можно сформировать diff | нужно доказать isolation, version gate и стоимость fork/materialization |
| Импортировать live, при ошибке восстановить snapshot | проще прототип | observers/undo/presence могли увидеть частичные правки; потеря concurrent edits; не рекомендован |
| Для sync считать частичный импорт отдельным результатом | соответствует контракту Loro; сохраняет допустимые remote updates | нельзя использовать для атомарного MCP apply_ops; нужен точный applied/pending/rejected отчёт |

Рекомендация для ops: staging/полная валидация и публикация под проверкой версии, без внешних эффектов до commit. Для sync — явный отдельный контракт частичного приёма. Это предложение: benchmark и concurrent observer tests нужны до принятия; текущий прототип ничего не публикует в приложение.

## Последствия и проверка

Не считать Err эквивалентом rollback. Проверять pending dependencies; принятие bytes не означает применение всех ops. DoD: corrupt/mixed packets, version race, observers без частичного события, отмена, отдельная undo group, соответствие dry_run/apply, бюджет памяти/16мс. Количественные затраты staging пока не измерены. Атомарность обязательной команды не ослаблена.
