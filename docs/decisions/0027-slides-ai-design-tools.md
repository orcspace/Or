# ADR-0027 — Навык дизайна презентаций и медиа-инструменты агента
Дата: 2026-10-16. Статус: принято в рамках поручения владельца; нейрогенерация исключена его уточнением 2026-10-16.

## Контекст
Встроенный AI-агент создавал презентации без правил оформления: мелкий текст, случайные шрифты, не было картинок и анимаций. Владелец попросил:
- навык дизайна, который агент читает до работы со слайдами;
- поиск и вставку изображений из интернета и из буфера;
- пакетную смену шрифтов, анимации;
- выгрузку в PDF и PowerPoint.

Ограничения:
- В проекте нет TLS-зависимости.
- UI-поток не должен ждать сеть или диск (REQ-04-008).
- Аргумент `bytes` у MCP ограничен 1 МиБ.

## Решение
1. **Навык** `mcp/skills/presentation_design.md` встроен в бинарник (`include_str!`). Инструмент `slides_design_guide` выдаёт его вместе с:
   - установленными шрифтами из списка кандидатов;
   - палитрами;
   - допустимыми эффектами;
   - ограничениями.

   Инструкции MCP-сервера и промпт чата требуют вызывать его до создания или переоформления презентации.
2. **Поиск изображений** `slides_search_images` идёт через публичный API Openverse (`api.openverse.org`): CC0/PDM/CC BY/CC BY-SA, без ключа. Ответ:
   - не больше 2 МиБ;
   - не больше 20 результатов;
   - для каждого: лицензия, автор и строка атрибуции.
3. **HTTPS** выполняет системный `%SystemRoot%\System32\curl.exe` (есть в Windows 10 1803+ и Windows 11). Он запускается отдельным скрытым процессом с параметрами:
   - `--disable --globoff --proto =https`, отключённые прокси; редиректы проверяются приложением;
   - `--max-filesize`, `--max-time`, `--fail`.

   Новая Rust-зависимость не нужна. Перед запуском URL проверяется (`check_url`):
   - только https;
   - без учётных данных;
   - не localhost, не `.local`, не однометочные имена;
   - не частные, loopback и link-local адреса IPv4/IPv6.

   Перед каждым запросом имя резолвится системой; если хоть один адрес непубличный (частные, loopback, link-local, CGNAT 100.64/10, бенчмарк 198.18/15, NAT64, v4-mapped и т. п.), загрузка отклоняется. Проверенный IP закрепляется через `curl --connect-to` (в том числе IPv6 на старом curl Windows 10), поэтому повторный DNS-ответ (rebinding) не используется. Редиректы curl не выполняет сам: каждый `Location` проходит ту же проверку, не больше 4 запросов (3 перехода).
4. **Загрузка** `slides_add_image_url`:
   - принимает только PNG/JPEG, не больше 16 МБ, за 45 с;
   - изображение уменьшается до 1920 px и перекодируется до ≤ 1000 КБ;
   - при `as_background` обрезается по центру под пропорции слайда.
5. **Генерация** `slides_generate_image` — локальная процедурная графика без сети:
   - стили gradient/radial/blobs/waves/grid/noise;
   - цвета палитры;
   - `seed`.

   Это ранее добавленная процедурная графика; раздел нейрогенерации, внешние image API и API-ключи не добавляются по прямому уточнению владельца. Для пользовательской картинки `slides_paste_image` читает только изображение из буфера на фоновом потоке; текст и содержимое буфера не возвращаются клиенту.
6. **Новые правки модели** выполняются через обычный `dispatch` → `Op::Replace` с автором-агентом, одной undo-группой:
   - `slides_format_text` — шрифт, размер, цвет, начертание для объектов, слайда или всей презентации;
   - `slides_animate` — анимация нескольких объектов с `stagger`;
   - `slides_align` — выравнивание и распределение;
   - `x`/`y`/`as_background` у `slides_add_*`.
7. **Экспорт** `export` пишет новый файл (никогда не перезаписывает существующий) в `Документы\TrineDocs\Экспорт` атомарной записью. Используется тот же `native::export`, что и в меню «Файл». Ответ содержит путь и предупреждения о потерях формата. Открытие произвольных путей агентом по-прежнему запрещено.
8. **Выполнение.** Поиск, загрузка, генерация, экспорт и выдача навыка работают на потоке `mcp-media`, не больше 4 заданий одновременно. UI-поток только:
   - снимает копию документа или размер слайда;
   - коммитит результат после повторной проверки прав MCP, `pending` и `base_version`.

   Тайм-аут ожидания на сервере для этих инструментов — 90 с, для остальных — 10 с.

## Последствия
- Нужен интернет и системный curl.exe. Без них поиск и загрузка возвращают `unavailable:`, генерация и экспорт работают.
- Лицензии изображений проверяет и соблюдает пользователь. Агент обязан добавить атрибуцию, но это не юридическая гарантия.
- Вход Fade/Fly In/Zoom, выделение Pulse/Spin, прямой путь Move и выход Fade Out/Fly Out/Zoom Out сохраняются в PPTX timing. На объект доступно до 33 шагов; сложные внешние эффекты приближаются с предупреждением. PDF/PNG статичны. MCP выгружает все показываемые слайды в папку; меню — в выбранный PNG и дополнительные нумерованные PNG рядом.
- У анимации есть поле `order`: шаги идут в порядке `element_ids`, а не слоёв. `order = 0` (старые файлы) — по слоям, раньше пронумерованных.
- `--connect-to` сохраняет имя TLS/SNI и поддерживает IPv6 без требования curl 7.57. Ответ читается через ограниченный pipe: лимит действует и без Content-Length. Нормализованный URL и правило закрепления используют одинаковый host. Системные прокси и curlrc отключены, чтобы не обходить проверку IP.
- Поиск изображений доступен любому MCP-клиенту через `slides_search_images`; встроенный чат дополнительно включает read-only веб-поиск провайдера. Никакая генерация картинок у провайдера не включается.
- Новые файлы экспорта публикуются атомарным hard link после fsync, без перезаписи: требуется файловая система с hard links (обычный NTFS); на неподдержанной возвращается ошибка. Дополнительные PNG получают свободные имена. Первая картинка из меню подчиняется обычному подтверждённому сохранению.
