# ADR-0001: Windows сначала

Статус: **принято владельцем**. Дата: 2026-10-13 Asia/Bishkek (2026-10-12 UTC).

Контекст: владелец явно разрешил сейчас работать только на Windows, Mac позже. Это разрешение о порядке работы/проверок, не удаление macOS arm64 из продукта.

Варианты: одновременно обе ОС / Windows сейчас и Mac позже. Выбран второй по прямому указанию владельца; дополнительных подтверждений не требуется.

Решение: активный target Windows 11 x64 build 22000+. Общая модель/ops/display list без Win-only business logic; platform adapters отделены. Mac-интеграция, сборка, спайки и VoiceOver явно отложены. Не объявлять глобальную фазу выполненной лишь по Windows.

Проверка: pure core tests в CI; реальное Windows 11 окно, IME/Narrator/Snap отдельные проверки. Hosted Server не равен Windows 11 desktop.
