# ADR-0002: Qt 6.12.0 и минимальный возраст релиза

Статус: **принято: соблюдать действующее ограничение**. Исключение ждёт владельца только если он захочет начать раньше.

Проверка: системное время 2026-10-12 UTC / 2026-10-13 Asia/Bishkek. [Официальный релиз](https://www.qt.io/blog/qt-6.12-released) датирован 2026-09-30, версия 6.12.0 ([release table](https://doc.qt.io/qt-6/qt-releases.html)). На дату проверки меньше двух недель. Точного времени публикации страница не даёт.

| Вариант | Плюс | Минус/затраты | Нужно от владельца |
|---|---|---|---|
| Дождаться полного возраста | стек/ограничения сохраняются | задерживается GUI; документация/core идут дальше | ничего |
| Исключение только для 6.12.0 | начать Qt раньше | ослабление жёсткого ограничения, риск раннего релиза; стоимость риска не измерена | явное исключение через ADR |
| Временно другой Qt | более старый релиз | смена жёсткого стека и повторная проверка | отдельное изменение стека |

Рекомендация: первый вариант. Qt не скачивать/собирать до прохождения age gate. 14 суток по датам наступают 2026-10-14; без точного времени релиза консервативная автоматическая граница — **2026-10-15 00:00 UTC**, чтобы не считать неполные сутки. Раньше можно уточнить timestamp первоисточником, не ослабляя запрет.

Продолжать независимый Rust core, spec/audit/traceability и подготовку тестов. Не объявлять совместимость CXX-Qt/Qt без реальной сборки. Ничего не запланировано автоматически на будущую дату.
