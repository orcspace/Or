# Навык: дизайн презентации TrineDocs

Прочитай целиком ДО создания или переоформления презентации. Для отдельной правки текста без редизайна полный процесс не нужен. Цель — презентация, которую не стыдно показать: чистая сетка, крупная типографика, одна мысль на слайд, единый стиль.

## 1. План до правок

1. Пойми задачу: тема, аудитория, длительность, язык, тон (деловой / учебный / продающий / творческий).
2. Составь сюжет: вступление → смысловые слайды → вывод или следующий шаг. Повестку добавляй, если она помогает аудитории; отдельное «Спасибо» не обязательно.
3. Объём по умолчанию 6–12 слайдов; 1 слайд ≈ 1 минута выступления.
4. Выбери ОДНУ палитру и ОДНУ пару шрифтов (см. §4, §5) и примени их через `slides_set_theme` до создания содержимого.
5. Для каждого слайда заранее определи рецепт из §6. Не повторяй один рецепт больше трёх раз подряд.

## 2. Сетка 960×540 pt (16:9)

- Поля: 60 pt слева/справа, 48 pt сверху, 40 pt снизу. Рабочая область x 60…900, y 48…500.
- Колонки: 12 колонок по 51.67 pt с промежутком 20 pt; две колонки — x=60,w=400 и x=500,w=400; три — w≈266.67 с шагом≈286.67.
- Заголовок слайда: x=60, y=48, w=840, h≈70. Содержимое начинается с y≈140.
- Выравнивай края объектов по одной линии; используй `slides_align` и одинаковые отступы (кратные 4 pt; ритм 8/16/24/32/48).
- Пустое место — часть дизайна. Объекты не касаются краёв слайда, кроме фоновых изображений и цветных плашек «в край».

## 3. Типографика

| Роль | Размер | Насыщенность |
|---|---|---|
| Титул презентации | 54–64 | bold |
| Заголовок слайда | 36–44 | bold |
| Подзаголовок / лид | 22–28 | regular |
| Основной текст / пункты | 20–24 (не меньше 18) | regular |
| Крупная цифра (stat) | 96–140 | bold, цвет акцента |
| Подпись, источник, атрибуция | 11–14 | regular, приглушённый цвет |

- Не больше 2 семейств шрифтов и 3 размеров на слайде.
- Пункты: ≤ 6 на слайд, ≤ 10–12 слов в пункте, без точек в конце. Длинный текст переноси в заметки докладчика (`slides_set_notes`).
- Не пиши заголовок ЗАГЛАВНЫМИ буквами целиком; курсив только для цитат.
- Текст должен помещаться в рамку: при 24 pt в ширину 840 pt помещается ~60 символов; высота строки ≈ 1.2 × размер.

## 4. Цвет

- Палитра: фон, текст, один акцент (+ при необходимости второй приглушённый). Акцент — для ключевых слов, цифр, плашек; не для длинного текста.
- Контраст текста к фону не ниже 4.5:1 (тёмный текст на светлом или белый на тёмном). Текст поверх фото — только на затемняющей плашке или на спокойной области.
- Готовые палитры ([фон], [текст], [акцент]):
  - **Graphite** — [255,255,255], [31,41,55], [230,106,45] (TrineDocs по умолчанию)
  - **Midnight** — [17,24,39], [243,244,246], [96,165,250]
  - **Ocean** — [240,249,255], [12,74,110], [14,165,233]
  - **Forest** — [247,250,245], [20,48,32], [34,139,84]
  - **Sunset** — [255,247,237], [67,20,7], [234,88,12]
  - **Royal** — [250,245,255], [46,16,101], [124,58,237]
  - **Mono** — [250,250,250], [23,23,23], [220,38,38]
  - **Sand** — [245,240,230], [60,50,40], [180,120,60]
- Тёмные темы хорошо работают для технологий и показов в зале; светлые — для отчётов и печати.

## 5. Шрифты (системные Windows)

Используй только установленные шрифты: `slides_design_guide` возвращает `installed_fonts`. Если шрифта нет, PDF/показ подставит замену.

| Пара (заголовок / текст) | Характер |
|---|---|
| Segoe UI Semibold / Segoe UI | современный, нейтральный |
| Bahnschrift / Segoe UI | технологичный, инженерный |
| Georgia / Segoe UI | редакционный, солидный |
| Cambria / Calibri | классический деловой |
| Calibri Light / Calibri | спокойный офисный |
| Trebuchet MS / Verdana | дружелюбный, учебный |
| Constantia / Corbel | мягкий, гуманитарный |
| Consolas — только для кода и чисел-идентификаторов | — |

Меняй шрифт и размеры пакетно через `slides_format_text` (по element_ids, слайду или всей презентации), а не по одному объекту.

## 6. Рецепты слайдов (координаты в pt)

- **Титул**: фон — подходящее фото (`slides_add_image_url`, `as_background:true`) или сплошной цвет темы; заголовок x=60,y=190,w=840,h=90, 56–64 bold; подзаголовок x=60,y=290,w=840,h=50, 24; акцентная линия/плашка x=60,y=170,w=80,h=6 (fill = accent, stroke_width 0).
- **Раздел**: плашка акцента на всю левую треть (x=0,y=0,w=320,h=540), номер раздела 96 bold белым, название раздела справа x=360,y=200,w=540, 40 bold.
- **Пункты**: заголовок + текст 22–24 pt с маркерами «• », до 6 строк; справа место под иллюстрацию или пусто.
- **Две колонки**: заголовок; колонки x=60,w=400 и x=500,w=400, y=150,h=330; каждая колонка с подзаголовком 24 bold.
- **Картинка + текст**: изображение на половину слайда в край (x=480,y=0,w=480,h=540) и текст слева x=60,w=380.
- **Изображение в край**: фото `as_background:true`, поверх плашка (rect, fill тёмный) x=0,y=360,w=960,h=180 и короткий белый заголовок.
- **Цифра**: одно число 120 pt цвета акцента x=60,y=140; пояснение 24 pt под ним; источник 12 pt внизу.
- **Цитата**: «» 40 italic по центру, x=120,w=720; автор 18 pt справа.
- **Сравнение / процесс**: 3–4 одинаковые карточки (rect + text) равной ширины, выровненные `slides_align` (`distribute_horizontal`).
- **Таблица / диаграмма**: только ключевые 3–7 строк; заголовок формулирует вывод («Выручка выросла на 32%»), а не тему («Выручка»).
- **Финал**: «Спасибо!» 54 bold, контакты 20 pt, тот же фон, что у титула.

## 7. Изображения

- Ищи фото по смыслу слайда: `slides_search_images` (Openverse, CC0/PDM/CC BY/CC BY-SA). Запрос — 1–3 английских слова (`mountain sunrise`, `team meeting`).
- Вставляй выбранное `slides_add_image_url` с `url` из результата. ОБЯЗАТЕЛЬНО добавь атрибуцию: подпись 11–12 pt внизу слайда или в заметках (`attribution` из результата поиска). Лицензии CC BY/BY-SA требуют указания автора.
- Если подходящего фото нет, используй цветной фон и простые фигуры. Картинка должна помогать объяснению, а не заполнять пустое место.
- Одно сильное изображение лучше коллажа. Сохраняй пропорции: задавай только width ИЛИ height, либо `as_background:true`.
- Не растягивай мелкие картинки на весь слайд: ширина результата поиска < 1200 px — используй не больше половины слайда.
- Картинку, уже скопированную пользователем из браузера или редактора, вставляй через `slides_paste_image`. Буфер не очищается. Если пользователь предоставил PNG/JPEG как bytes, используй `slides_add_image`. Нейрогенерация и ключи провайдеров для этого не нужны.

## 8. Анимации и переходы

- Сдержанно: один тип перехода на всю презентацию (`fade` 0.4–0.6 с или `push` для сюжетной последовательности).
- Анимации объектов — только для раскрытия по шагам: пункты списка, карточки процесса, столбики диаграммы. `slides_animate` с element_ids в порядке показа, effect `fade` или `fly_in`, trigger `on_click` (по щелчку) или `after_previous` со stagger 0.15–0.3 с. Шаги идут в порядке element_ids, после анимаций, заданных на слайде раньше; повторный `slides_animate` переносит объекты в конец последовательности.
- Не анимируй заголовки, фон и подписи. `zoom` — максимум для одного акцентного объекта.
- Поддержаны вход Fade/Fly In/Zoom, выделение Pulse/Spin, прямое перемещение Move (dx/dy), выход Fade Out/Fly Out/Zoom Out. `append:true` добавляет следующий эффект объекта; `slides_set_animation` с animations задаёт всю цепочку. Эффекты и переходы записываются в PPTX; не обещай проверку в PowerPoint без фактического открытия файла. PDF и PNG статичны — скажи об этом, если выгружаешь в них.

## 9. Порядок работы инструментами

1. `slides_design_guide` (этот навык) → `slides_list` / `slides_read`, запомни version и ID.
2. `slides_set_size` при необходимости (960×540), `slides_set_theme` {name, background, foreground, accent, font}.
3. Слайды: `slides_add_slide` (layout title|content|two_content|blank) → `slides_update_element` для текста плейсхолдеров или `slides_add_text` / `slides_add_shape` с x, y, width, height.
4. Оформление: `slides_format_text` (шрифт, размер, цвет, bold), `slides_align`, `slides_set_z_order`.
5. Изображения: `slides_search_images` → `slides_add_image_url`; или `slides_paste_image` для уже скопированной картинки.
6. Переходы: `slides_set_transition` на каждом слайде; анимации: `slides_animate`.
7. Заметки докладчика: `slides_set_notes` для каждого смыслового слайда.
8. Проверка: `slides_read` + `inspect_document` kind=bounds|readability; исправь выход за край, мелкий шрифт, слишком длинный текст.
9. Выгрузка: `export` с format_extension `pdf` или `pptx` — файл попадёт в «Документы\TrineDocs\Экспорт»; `png` создаёт там папку с картинкой каждого показываемого слайда. Сообщи пользователю путь и предупреждения из ответа.

## 10. Чек-лист перед ответом

- [ ] Одна тема, одна пара шрифтов, один акцент на всей презентации.
- [ ] Ни один объект не выходит за 960×540 (кроме фона в край); поля соблюдены.
- [ ] Основной текст ≥ 18 pt, ≤ 6 пунктов, заголовки формулируют мысль.
- [ ] У найденных изображений есть подпись с атрибуцией источника.
- [ ] Переходы единообразны; анимации только там, где раскрывают мысль.
- [ ] Заметки докладчика заполнены.
- [ ] Сказано, что изменено, куда сохранён экспорт и какие ограничения формата есть.
